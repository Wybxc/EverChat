# EverChat

面向个人使用、可自行部署的 AI 聊天应用。在一个界面中接入不同供应商和模型，同步对话、管理分支并保留自己的记录。消息提交成功后，即使关闭页面或暂时断网，云端仍会继续生成；重新打开即可读取已保存的结果。

## 可以做什么

- **自由选择模型**：支持 OpenAI Chat Completions、OpenAI Responses、Anthropic 和 Gemini 协议，兼容 DeepSeek 等供应商；支持自定义模型名称、能力和思维强度。
- **保留对话版本**：原位编辑提问或回答、重新生成、在气泡下切换分支，也可复制整段对话或从某条消息开始新对话。
- **阅读与查找**：流式显示正文和思考，支持 Markdown、代码、数学公式和图表；提供全文搜索、关键词高亮及回答间导航。
- **使用文件与联网工具**：上传、粘贴或拖入图片和文件；PDF 可完整提取文字后选择页码或片段。配置联网服务后，可在聊天框直接开关搜索与网页读取。
- **管理提示词和上下文**：快速切换预设、设置模型专属提示词、控制上下文预算，并按需压缩历史。
- **跨设备使用**：支持安装为 PWA、离线阅读和待发送消息，以及可选的回答完成通知。
- **分享与用量**：创建可删除、可过期的只读分享链接；查看供应商／模型用量、费用估算和趋势。

界面支持简体中文、English，以及浅色、深色和跟随系统外观。

## 开始使用

1. 打开部署者提供的网站，使用获准身份登录。
2. 进入「设置 → 供应商」，添加供应商，填写名称、API 类型、基础地址和密钥。
3. 获取或手动添加模型，勾选需要使用的模型；在聊天框选择模型后发送消息。设置会自动保存。

EverChat 需要你自己的供应商 API 密钥；模型、联网服务和托管费用由相应服务商计算。「用量统计」中的金额为估算，不代替供应商账单。当前面向个人空间，获准登录的身份共享同一空间。

更多操作见[使用指南](docs/user-guide.md)。准备自行部署时，请阅读[部署指南](docs/operations/self-hosting.md)。

## 本地运行

需要 Node.js 22.12+（或 24+）和 pnpm 12。在项目根目录执行：

```sh
pnpm install
pnpm dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)，点击「重新登录」进入本地空间，再按上述步骤配置供应商。日常开发无需创建环境变量文件；本地数据在重启后保留，重启开发服务后需重新登录。

真实 Access 联调、环境配置和本地数据说明见[开发指南](docs/development.md)。

## 参与贡献

欢迎改进功能、修复问题、补充文档和翻译。提交问题时请说明复现步骤、预期与实际结果、浏览器／PWA 环境；涉及模型时附上供应商、协议和模型 ID，隐去密钥及私人对话。

修改前先查看[模块边界](docs/architecture/modules.md)；界面调整遵循[前端设计规范](docs/architecture/frontend-design-standard.md)，新增文案遵循[翻译维护说明](docs/features/i18n.md)。保持改动聚焦，并为行为变化补充相应验证。

```sh
pnpm format:check
pnpm test
pnpm build
```

使用 `pnpm format` 格式化代码。涉及浏览器交互、后台任务或离线能力时，按[测试说明](tests/README.md)运行对应测试；完整检查入口为 `pnpm check`。运行环境、测试隔离和性能测量详见[开发指南](docs/development.md)。

提交说明应包含修改目的、用户可见的行为变化和验证结果。请勿提交密钥、本地聊天数据或运维备份。
