# EverChat

个人自用的云端 AI 聊天应用。客户端断网或关闭页面后，已经提交的回答仍由 Conversation Durable Object 的 Alarm 在后台生成；重新打开或换设备后读取持久化结果。

## 本地运行

需要 Node.js 22.12+（或 24+）、pnpm 12。所有命令在项目根目录执行。

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173，点击「重新登录」进入本地空间。在空间设置中添加供应商并选择默认模型后即可发送消息。日常开发由 Node 临时签发本地身份，只监听 loopback；私钥不传入 Worker 或浏览器，生产构建不包含本地签发入口。每次重启开发服务后需重新登录。

真实 Access 联调使用 `pnpm dev:access`，需要时在本机创建被 Git 忽略的 `.dev.vars`，填写 `ACCESS_TEAM_DOMAIN`、`ACCESS_AUD`、`ACCESS_ALLOWED_EMAILS` 和 `APP_ORIGIN`，通过已经配置域名保护的命名 Tunnel 访问。它采用生产 JWT 验证入口，不能用日常开发 Cookie 登录；隧道入口必须独立配置可信 Origin 和 Access 应用 AUD。日常开发无需创建环境变量文件，供应商通过网页设置。

新对话位于 `/`，每个已创建或离线待发送的对话使用 `/c/:conversationId`。点击侧栏以 SPA 方式切换，支持浏览器前进／后退、直接打开链接和刷新；链接也可在新标签页打开。URL 决定当前对话，访问 `/` 始终进入新对话。各对话草稿独立保存。

对话右上角的管理菜单支持改名、置顶和删除。侧栏使用统一对话列表，置顶条目优先，其余按最近消息活动排列并按时间分组；改名和整理不改变活动时间。原归档对话直接回到列表，内容、URL 和置顶保持不变。删除需要确认，会停止生成、清除正文和本设备草稿；其他设备联网同步后清理对应缓存与待发送消息。已删除的 URL 显示错误，可开启新对话。

管理菜单也可以复制当前对话。复制会创建新的对话 URL、消息 ID、附件 ID 和私有 R2 文件，保留已保存的正文、思考、模型信息与消息关系；源对话删除后，副本仍可独立预览、下载和问答。完整复制包含所有已保存原文件，指定消息复制只包含该路径引用的文件。复制完成前副本不出现在列表，响应丢失后重试沿用同一请求，不重复写文件。规则见 [附件复制](docs/features/attachment-copies.md)。

每条用户和助手消息的「复制到新对话」只复制从根消息到所选消息的父链路径，包含所选消息，不包含旁支或后续消息；保留会话参数和生成信息。复制到提问为止时，下一次发送会保留这条提问作为上下文。生成中的回答只复制云端已保存前缀，在副本中标记为未完成；原任务继续运行，复制操作不调用模型。

侧边栏每个已保存对话都有操作菜单，可重命名、置顶、复制链接、复制对话或删除；离线仍可复制链接。操作非当前对话不改变正在阅读的 URL、分支和草稿。完整复制保留全部历史，并使用目标对话自己的阅读分支；等待期间已经导航时，副本只加入列表，不抢占页面。尚未确认创建的本机待发送对话不提供云端管理操作。

侧边栏显示全列表的等待生成、生成中及停止中状态，可从菜单查看生成分支或停止该任务。当前对话即时同步，其他对话复用低频列表刷新；失联或状态过期显示静态“生成状态待同步”。旧菜单不会停止后续新任务，任务状态不随副本或备份继承。

每条用户和助手消息都可以复制或引用。引用会将消息正文转为 Markdown 引用并填入输入框；已有草稿保留在前面，输入框会重新获得焦点。

提问和回答下方均有直接编辑按钮，点击后在原消息位置编辑文本，底部草稿和附件独立保留。Enter 换行、Mod+Enter 保存、Escape 取消；编辑草稿按对话缓存，切换分支、切换对话或刷新后可继续修改。修改提问会使用当前模型重新生成；修改回答保存为新版本，原回答仍保留，操作不调用模型，新版本标记「手动编辑」。用户和助手消息均可单独删除；确认后清空正文与思考，保留父链与删除标记；连接后续的节点显示「消息已删除」，删除末端则回退到可用版本。后续上下文跳过已删除内容；删除提问后，其回答也不进入后续上下文。正在生成时先停止或等待完成，再编辑／删除。手动编辑失败会保留输入，删除确认默认聚焦取消。

已完成的助手消息可以选择「从这里继续」。编辑用户消息或重新生成回答会保留原消息，并在选定分支上生成新版本；后续发送只使用当前分支的上下文。生成中的失败或停止消息仍可单独重新生成。

输入框工具栏保持单行，窄屏通过「更多参数」调整思维强度、联网和查看上下文；发送／停止始终可见。上下文入口显示 Token 近似估算，并保留将省略的历史条数提示。会话参数可设置上下文预算和最近历史消息条数，两者留空时按模型窗口选取完整轮次；系统提示词、摘要和本次输入超过预算时保留草稿并阻止发送。云端决定最终上下文，已接受任务的估算保存在「生成信息」中。输出预留不会设置请求输出上限；未知窗口明确使用保守回退。详细规则见 [上下文预算](docs/features/context-budget.md)。

对话右上角「压缩历史」可以选择摘要模型和覆盖边界，调用前提示额外供应商费用。会话参数可开启自动压缩（默认关闭），配置阈值和摘要模型；发送达到阈值时先保存完整摘要，再启动回答，失败不重复调用模型。摘要独立持久化并流式显示 Markdown，保留原始消息，支持查看、重新生成、删除和停用。后续回答只使用匹配当前分支的已完成摘要，失败或中断摘要不替换原文；复制和备份保留覆盖关系。详见 [历史摘要](docs/features/history-summaries.md)。

已保存对话的右上角「管理对话文件」可上传、取消、下载及删除图片、文本、代码、CSV 和 PDF 原文件，并同步到其他登录设备。单文件最多 5 MiB，每对话最多 64 个文件／32 MiB；文件保存在私有 R2。聊天框支持 PNG／JPEG／WebP 图片选择、粘贴、缩放、预览和视觉模型问答；「添加文件」支持 TXT／Markdown／代码／受限 CSV 和含文字的 PDF，提供私有文本预览及问答。普通文本源文件最多 128 KiB、提取结果最多 64,000 字符；PDF 原文件最多 5 MiB，全文和原文件共同计入对话 32 MiB 容量，不再限制 50 页或 64,000 字符。PDF 使用浏览器独立 Worker 完整提取，可按所选模型预算选择页码或原文片段，保留全文并随复制／备份恢复选区。模块加载与提取停滞分别受 30 秒保护，不处理扫描图片和加密文件；保存完成后接受的任务不依赖页面继续在线。包含文件的独立复制及备份恢复均已接入。部署与清理规则见 [对话文件](docs/features/attachments.md)和 [PDF 文本输入](docs/features/pdf.md)。

「设置 → 用量统计」提供供应商、模型、请求和交互式折线趋势图。默认采用 models.dev 快照中的模型价格，允许手动覆盖；历史请求保留当次价格快照，未知价格不计为免费，估算结果不代替供应商账单。

点击右上角搜索按钮或按 Ctrl／⌘ F 可查找当前对话的正文与思考内容。搜索忽略大小写，按普通文字匹配，支持跨 Markdown 格式的短语；关键词最多 200 字。上下按钮或 Enter／Shift+Enter 在匹配间循环，Escape 关闭并返回搜索按钮。定位会展开折叠的思考区；查找旧内容时暂停跟随滚动，点击「跳到底部」可恢复。流式内容更新计数时保留当前匹配，不反复跳转。

消息溢出视口时提供「跳到顶部、上一条回答、下一条回答、跳到底部」，平时隐藏，鼠标靠近导航区、手动滚动或触屏轻点消息区时显示，停止交互约 2 秒后淡出；键盘聚焦时保持可见，流式自动滚动不唤出按钮。前后定位只遍历当前分支的回答；在长回答中点击上一条会先返回本条开头。顶部和前后定位暂停流式跟随，底部恢复跟随。桌面宽屏竖排，窄屏在输入框上方横排。

侧栏「搜索」或 `Mod+K` 打开全局搜索弹窗，搜索全部未删除对话的本地标题、联网正文与思考，支持分页，结果标题与摘要高亮匹配关键词；空查询显示近期对话。关闭按钮固定在弹窗顶部，结果独立滚动，手机布局保留外边距和安全区。方向键选择、Enter 打开、Escape 关闭，结果链接也可在新标签页打开。选择正文结果会恢复对应分支并高亮消息；仅开关搜索不会改变 URL 或草稿。离线可查本机已读取的标题和当前对话，跨对话正文搜索需要联网。

移动端可从左侧应用内部 16–40 CSS px 区域向右滑打开侧栏，在侧栏非交互区域向左滑关闭。保留系统边缘返回、纵向滚动、输入控件、菜单和横向内容滚动；多指或取消操作不会提交侧栏状态。

`Mod+J` 开启新对话并聚焦输入框，保留原对话草稿，首次发送前不创建云端空对话。`Mod+Shift+L` 聚焦输入框，`Mod+B` 在非文本编辑区域切换侧栏；右上角菜单可查看快捷键。`Mod` 在 macOS 为 ⌘，其他平台为 Ctrl。快捷键遵循弹窗、输入法和文本编辑的作用域。

右上角文件菜单可以下载当前已保存的对话为 Markdown、纯文本或 HTML，也可以下载带版本号的 `.everchat.zip` 备份。ZIP 包含正文、思考、消息关系、模型信息、通用设置、全部已保存原文件和解析文本，不包含 API 密钥、流式游标或后台任务状态；正在生成的未保存尾部不会进入文件。浏览器 Worker 校验存档，导入有进度及取消功能，完整保存后发布独立对话，源对话删除后仍可预览和问答；响应丢失后重导同一存档不会重复写文件。当前无附件 JSON 备份也可导入。限制和清理规则见 [附件备份](docs/features/attachment-backups.md)。

消息快照、同步事件和备份统一使用 `parts`：正文为 `{ type: 'text', text }`，思考为 `{ type: 'reasoning', text }`。当前每种内容至多一个部分，思考排在正文前，空内容不创建部分；这是按内容类型汇总的结构，不记录原始 SSE 事件的交错顺序。上下文、剪贴板复制和引用只读取正文，搜索及导出可读取思考；对话副本保留两个通道。删除消息的 `parts` 为空数组。

“设置 → 对话 → 自动标题”可选择独立标题模型，自动命名默认关闭。启用后，新对话首条回答完成时只命名一次；也可从对话菜单主动生成标题。每次命名单独调用模型，手动改名受版本保护，后台中断不会自动重复付费调用；模型无效时保留原题。

正文和思考支持 KaTeX 数学公式：行内 `$…$`／`\(…\)`，块级 `$$…$$`／`\[…\]`；长块级公式可在自身区域横向滚动。代码与转义美元保持原样，普通价格不按公式解析。公式插件按需加载，PWA 缓存公式模块与字体，支持已保存消息离线重开。

Markdown 模块加载失败时保留可搜索的原文和输入框。若内部懒加载模块失败，联网后点击消息下方的「重新加载」可重开当前页面并恢复草稿；正在云端生成的回答继续执行。

依赖锁文件为 `pnpm-lock.yaml`。本地聊天和供应商配置保存在 `.wrangler/`，重启开发服务器后仍保留。`.npmrc` 将 pnpm 的存储放在项目内，便于受限工作区运行。

## 代码格式化

使用 Prettier 统一格式：单引号、分号、两空格缩进和 LF 换行，行宽为 100。VS Code 安装工作区推荐的 Prettier 扩展后，保存文件时自动格式化。

```sh
pnpm format
pnpm format:check
```

缓存、构建产物、密钥文件、依赖锁文件、生成的模型目录及测量 JSON 不参与格式化。

## 接入真实模型

设置分为「通用」「供应商」「对话」「预设」「联网」五个 Tab，修改后自动保存。停止输入约 600ms、离开输入框或关闭窗口时保存；失败会保留当前编辑并提供重试。关闭按钮和 Tab 固定显示，内容区域独立滚动。

在「供应商」中添加供应商，配置名称、接口协议、API 基础地址和密钥。新供应商名称初始为空，填写非空名称后才能自动保存。修改接口协议或 API 端点会保留其他输入和模型配置。模型使用复选框启用或禁用，并可编辑 ID 和显示名。获取的新增模型默认禁用，手动添加的模型默认启用；重新获取保留已有模型的显示名和启用状态。

「对话」中的默认模型只包含已启用且配置密钥的模型。聊天输入框可以为每次请求选择模型，选择随离线请求保存。普通回答重新生成使用点击时输入框选择的模型及对应提示词和思维参数，气泡名称固定为本次实际模型，并保留未发送草稿；摘要重新生成沿用摘要配置流程。模型设置中可以继承统一系统提示词或配置专属提示词，并配置思考能力及可选思维强度；实际强度在聊天框选择。供应商实际返回的思考内容始终保存并以 Markdown 流式显示，可在消息中折叠。系统提示词和请求输出 Token 上限在「对话」Tab 中设置。请求输出上限默认留空，使用供应商或 SDK 的默认值；填写正整数可设置上限，清空后取消。

模型设置逐字段显示能力及来源。手动设置优先于供应商报告、主动测试和模型目录；内置精简快照支持离线识别，进入供应商设置时更新公共目录并缓存 7 天。未知图片／工具能力允许主动尝试，明确不支持或手动禁用时拦截；联网仍需用户开启。模型能力折叠区可「测试能力」，最多发送 3 次模型请求，核验文本、图片和实际工具调用，仅保存确认成功的能力，失败不覆盖配置。名称、启用状态、提示词和手动覆盖保持不变；能力数据随备份恢复，任务接受后固定。模型最大输出不会自动设置请求输出上限。详细定义见 [模型元数据](docs/features/model-metadata.md)、[改进计划与验收](docs/plans/model-capability-improvement-plan.md)、[工具执行](docs/architecture/tool-workflow.md)和[联网服务](docs/features/web-tool-service.md)。

「联网」Tab 配置 Tavily API 密钥及全局 UTC 每日请求上限，显示今日已用次数。密钥默认遮蔽，点击查看后只保留在当前设置内存，切换 Tab 或关闭设置会隐藏；不会进入本机缓存或备份。聊天框「联网」打开会话参数，可分别开启搜索和网页读取，每个新对话默认关闭。任务通过 DO／Workflow 在后台有限执行，助手消息展示工具过程和来源链接。离线待发送、复制和备份保留会话选择；复制与恢复不会执行工具。每日上限按请求尝试计数，不代表供应商 credits 或金额预算，模型和搜索服务费用另计。

颜色模式支持浅色、深色和系统偏好。默认跟随设备外观变化。

右上角「会话参数」设置当前对话的系统提示词、Temperature、Top P 和输出 Token 上限，修改自动保存并跨设备同步。提示词默认继承模型／全局配置；开启自定义后，空文本表示不发送系统提示词。输出上限可选择继承全局、未设置或自定义；Temperature／Top P 留空使用供应商默认值，不支持的模型或思考模式隐藏对应参数。Anthropic 的采样参数只选一项。

新对话的参数先保存在本机，第一条消息被云端接受后成为该对话的配置；添加附件提前创建对话时也会保存这些参数。离线待发送消息保留发送时选择的会话参数，云端已接受任务固定配置快照；后来修改配置不会改变已有任务。保存失败保留有效草稿，重开后继续保存；复制对话和备份包含会话参数。点击「恢复继承」可清除全部会话覆盖并关闭联网工具。

空间设置的「预设」Tab 可以添加、编辑、删除命名系统提示词，修改自动保存；失败后保留有效的本机草稿并可重试。在「会话参数」里选择预设会复制其内容，之后修改或删除预设不会改变已应用的会话，也不会改变已接受任务。已读取的预设可离线使用；空提示词预设表示不发送系统提示。最多保留 200 个预设，每个提示词不超过 64,000 个 UTF-16 码元，全部名称与提示词的 UTF-8 内容合计不超过 512 KiB。

备份包含提示词预设，导入会保留现有预设；相同内容不重复创建，同 ID 的不同内容以新 ID 导入。当前只处理现有备份结构，不迁移早期格式。退出并清除本地记录会清除预设缓存与草稿。

回答与摘要的操作区直接显示已报告的 Token 和生成耗时，点击打开「生成信息」，查看输入、输出、缓存和思考 Token，以及云端排队、首 Token 和生成耗时。缺失字段不补成 0，中断前返回的用量标为部分报告；这些数值不代表最终账单。首 Token 从云端调用模型开始，计至收到首段可解析的正文或思考；不包含排队或客户端同步等待。复制和备份恢复保留原回答的生成信息，手动修改出的回答不继承它。

供应商失败保留已有回答与思考，默认显示短提示；展开「错误详情」可查看和复制经过脱敏的阶段、HTTP 状态、模型、请求 ID 等诊断，并打开对应供应商设置。详情不包含完整请求、密钥或上游 HTML；供应商的认证失败不会退出 EverChat 的 Access 登录。模型列表和能力测试沿用同一诊断规则。

## 部署到 Cloudflare

先配置下文的 Cloudflare Access 应用，再创建私有 R2 桶并部署。应用不再使用共享密码或 session secret。

```sh
pnpm exec wrangler login
# 可选：通过环境变量配置默认模型密钥时使用；网页配置无需此步骤。
pnpm exec wrangler secret put AI_API_KEY
# 先在账户启用 R2；只需为目标账户创建一次，保留私有访问。
pnpm exec wrangler r2 bucket create everchat-attachments --storage-class Standard
pnpm deploy
```

正式域名为 `chat.wybxc.cc`。已在团队 `wybxc.cloudflareaccess.com` 创建覆盖整个域名的 self-hosted Access 应用，仅允许 `wybxc@qq.com`，启用邮件验证码登录。该应用的 AUD 已写入 Wrangler 的 `ACCESS_AUD`；`ACCESS_TEAM_DOMAIN`、`APP_ORIGIN`、`ACCESS_ALLOWED_EMAILS` 已在配置中固定。AUD 是应用标识，不是密钥。保持 `workers_dev: false` 和 `preview_urls: false`；迁移到其他域名或账户时须先配置对应的边缘保护，仅填写变量不会启用 Access。

Worker 使用 `jose` 验证断言的签名、issuer、audience、有效期和允许身份。缺少配置或验证服务不可用时拒绝业务访问。无需应用密码或 EverChat 自签登录 Cookie；部署后可通过网页配置模型。部署将创建 Worker、两个 SQLite Durable Object namespace 及有限工具编排使用的 Workflow 定义；首次启用服务时按 Cloudflare 提示完成账户配置。费用以账户当前套餐和实际用量为准。

生产构建有 PWA manifest、应用图标及 Service Worker，支持安装和离线重新打开已访问的应用。安装只预缓存启动页面、静态依赖脚本、样式和图标；Markdown、公式字体、代码高亮、图表、PDF 解析器及字体在使用时缓存，最多保留最近使用的 192 个静态资源，普通更新复用相同哈希的资源。首次使用这些模块需要联网，缓存完成后可离线使用；未下载的渲染模块保留可读文本，附件上传仍需联网。API、认证响应和附件原文不进入此静态缓存。通用设置提供安装、版本检查、确认更新和缓存修复；更新前协调所有标签页保存草稿和检查点，未保存设置、上传或结果未知的写请求会阻止刷新。修复先下载新一代必需静态缓存，确认所有标签页准备完成后切换并清理旧应用缓存（含按需模块缓存）；保留对话、待发送请求与其他缓存，下载失败继续使用原版本。手动检查区分离线、服务异常和更新文件异常，设置内可展开或复制脱敏诊断；后台瞬时失败不弹全局错误。Cloudflare 显式关闭 HTML 规范化重定向，使预缓存首页直接返回 200；首次安装失败后重新获取注册对象再重试，正常安装不再误报检查超时。开发模式不注册 Service Worker。客户端缓存、快照和离线草稿优先保存在 IndexedDB（由 `idb-keyval` 管理），并保留 localStorage 作为故障回退；共享设备上用“退出并清除本地记录”。主题偏好仍使用 localStorage，以便页面启动前立即恢复主题。

## 实现与边界

```text
PWA → Cloudflare Access → Worker（JWT 验证、API）→ Conversation Durable Object（SQLite、事件序号）
                              ↓ 原子保存输入、配置、outbox + alarm
                            Conversation Alarm → 模型供应商
                              ↓ 增量日志 → 终态快照
                            Conversation → 休眠 WebSocket → 多设备
```

- `Library` Durable Object 保存个人会话索引、供应商配置及附件登记／清理信息，`Conversation` 每个对话一个实例。私有 R2 保存原文件和有界文本解析结果；暂不使用 D1；登录由 Cloudflare Access 管理。
- 删除先在 Library 保存永久标记，再中止 Conversation 的上游请求、清空 SQLite／任务 Alarm、保存最小删除标记，最后移除索引。Library Alarm 每批最多清理 16 项，失败后 30 秒重试；实例在清空与写入标记之间重置时，Library 标记仍阻止迟到任务和创建请求。重复删除是幂等的，同 ID 的创建、提交和读取返回 410，不重新调用模型。
- `GET /api/conversations?after=<cursor>` 返回对话索引和每页最多 256 条删除记录，客户端读完分页后保存游标。这样没有打开被删除对话的设备也能清理缓存与离线 outbox。服务端及本地删除标记长期保留，防止旧设备重新恢复数据；它们仍占少量存储，删除不表示账户存储归零。DO 清空存储的行为依据 [SQLite 存储 API](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)。
- 在同一个存储事务中保存输入、配置快照、请求 ID、任务 outbox 和 Alarm；提交成功后才确认接受。新任务固定执行器 `do-v1`，由 Conversation Alarm 认领并执行。浏览器保存提交 request ID，未知网络结果继续用它重试。
- 每个会话只允许一个活跃生成，不同会话可同时生成。供应商原始字节约每 100ms 或达到 8 KiB 封装预览，约每 1.5 秒或达到 32 KiB 批量保存；一个提交最多 64 KiB、32 个微批次。保存时保留预览的序号和字节边界，结束、失败或取消时立即保存尾部并原子整理终态快照。
- 预览与保存确认分别发送。客户端维护实时视图和持久化快照，只有已保存内容可缓存、导出或用于重连。缓存最多每 2 秒写入一次，完成、切换对话或页面隐藏时立即刷新；尚未确认的预览显示“保存中”。
- 事件序号与增量偏移用于去重和检查缺口；最近 500 个持久化事件支持回放，游标过期时恢复完整快照。重连先恢复已保存内容，再补当前内存尾部。未确认接收的预览窗口限于 128 KiB，过慢订阅主动断开后重新同步，不阻塞云端保存或其他客户端。
- 当前只维护现有数据结构、DO 执行器与 `raw-sse-v1` 协议，不提供旧客户端、旧任务或旧格式自动迁移。偏移对应供应商原始字节；字节以 base64 保存在同步帧中，允许切在 UTF-8、SSE 或 JSON 中间。客户端和云端快照／终态整理共用 `eventsource-parser` 与四种协议适配，解析检查点保存未完成事件和字符，确保重连不会丢失半个片段。
- `Message` 的正文和思考只通过内容部分传递，不在快照或备份中重复输出平铺字段。SQLite 仍分别保存两个文本通道，读写时映射为当前内容部分；原始流接收和提交频率不变。浏览器快照使用 `snapshot:parts-v1` 缓存键，重新获取云端数据；备份仅接受当前内容部分结构，拒绝重复类型、倒序部分、未知类型和多余的部分字段。
- DO 在接收流时只封装、转发和批量保存原始字节，不逐 Token 解析正文。读取生成中快照或整理终态时解析已保存日志；完成原因与用量由云端验证并保存，不依赖客户端提交。最终正文、思考、状态、用量和日志清理在同一个事务内保存。下一次读取上游前等待存储提交，限制保存落后时的缓冲。
- 完整快照由 DO 构造 JSON Response，经 RPC 传输响应体；Worker 完成鉴权和索引检查后直接转发，避免在 10ms 免费 CPU 路径中反序列化并重新编码大段历史。
- 供应商调用的自动重试次数为零；任务领取也是幂等的。启动上游前确认认领已持久化。供应商失败时保存缓冲尾部并标记失败；存储错误保留最近检查点，不发布虚假的完成状态。用户主动重新生成、编辑消息都保存为新版本。
- 对话使用消息父链维护当前分支；气泡下的版本箭头只显示一条父链，切回时恢复此前选中的后续；「从这里继续」可以另起追问。普通发送必须指定当前路径最后一条未删除的完成消息作为 `parentId`，新对话显式传 `null`；没有全局最新消息回退。复制到用户提问为止或失败回答后续聊均支持用户父节点；未完成的助手输出不进入上下文。历史版本仍保留在对话中，复制对话会重建父链和版本关系；只复制选定路径时，路径外的修订引用置空。手动编辑回答只创建完成的新版本，不复制原任务的思考和用量数据。
- 分支位置通过 `/c/:id?branch=:messageId` 记录，支持刷新、前进／后退和分享；阅读选择保存在本机，远端新版本和迟到的发送响应不会抢占位置。对话内搜索和文本导出只使用当前路径；全局搜索、完整复制与备份保留全部分支。生成中切换路径不会重启或停止模型，隐藏任务通过紧凑状态返回。
- 单条删除清空正文、思考和结果元数据，保留消息 ID、父链与删除标记。删除同时清理旧回放事件，旧游标恢复完整快照；搜索索引由持久化 outbox 更新。删除标记随同步、复制和备份保留，文本导出跳过已删除消息。已删除消息的请求 ID 继续保留并拒绝迟到重试，避免重新创建；已有分支的父链不会被切断。
- 停止先保存取消意图，DO 立即终止上游并提交已接收尾部，再写入终态；尾部写入失败时标记失败并保留最近检查点。供应商是否及时停止计费由其服务决定。
- Worker/供应商重启或网络故障不能恢复同一 token 生成。新实例发现已经运行但失去上游连接的 DO 任务，会保留检查点并明确标记中断，供用户主动重新生成；不重复调用模型。DO 保留 14 分钟供应商超时和 15 分钟看门狗 Alarm。
- 本地断网前最后一条尚未确认提交的消息可能已在云端接受；此时保留同一 request ID 重试。离线缓存仅属于此浏览器，首次访问和登录需要联网。
- 整个域名由 Cloudflare Access 保护，Worker 再校验 JWT 与指定邮箱；同源写入检查继续保留。WebSocket 在 JWT 到期或最长 5 分钟订阅租期后重新握手，不为每个增量查询身份。退出先清除本地记录再访问 Access 退出入口，后者会影响此账号的其他 Access 应用；离线退出保持锁定，联网后可完成远端退出。获准身份仍共享同一个个人空间。
- 当前保留最多 128 个会话，每个 1,000 条消息。启动生成前，完整历史 JSON 的 UTF-8 大小最多 4 MiB，SQLite 分配最多 16 MiB；为新内容、解析检查点与流式日志预留空间。流式提交超过 30 MiB 会回滚并停止，终态保存最多 32 MiB。已有历史继续可读，不自动截断或删除；生成结束清除不再使用的任务上下文。128 × 32 MiB 约为 4.295GB，是应用保留预算，其他应用仍共享账户存储额度。SQLite 已分配页不一定随日志清理缩小。
- 容量不足返回明确的 507 错误，不自动重新调用模型。同步失败保留草稿和缓存、显示“重新同步”，暂停自动重试；平台存储错误的内部诊断不会直接显示给用户。账户存储完全耗尽时可能无法写入终态，此时不发布完成确认。
- 输入、手动编辑及回答使用相同的序列化文本规则：单条消息正文与思考合计最多 768 KiB，包含 JSON 转义，不再按 16,000／100,000 个字符截断。普通回答取消固定的 4 MiB 原始协议总量限制，仍受上述数据库容量与 14 分钟生成时长保护；工具每轮原始流最多 8 MiB，私有续接记录最多 1 MiB。单个 SSE 事件最多 1 Mi 个 UTF-16 码元，未完成事件的 JSON 内容另限 1 MiB。日志回放按游标逐条读取，避免在内存中复制整份原始日志。
- 系统提示词最多 64,000 个 UTF-16 码元。显式输出 Tokens 与模型元数据共用 1–10,000,000 的校验范围，仍验证已知模型最大输出；默认保持不设置。一次任务的上下文与供应商配置 JSON 合计最多 1,900,000 字节，为 SQL 整行预留余量。发送历史继续按模型窗口、会话预算和消息数选择完整轮次，不静默截断单条消息。
- 每供应商最多 1,000 个模型，目录最多 10 页；超过数量、页数或响应保护大小时明确报错，保留原配置。目录获取在 Library DO 内完成，普通 Worker 转发 Response，避免在免费层 10ms HTTP CPU 路径中解析大目录。摘要最多 100 条；工具任务历史最多 1,000 条，与现有消息容量一致。完整政策、保留边界及后续放宽条件见[免费层资源政策](docs/architecture/free-tier-resource-policy.md)。
- 图片、文档、PDF、附件复制与备份沿用独立的大小、数量、解析和保留预算；Tavily 搜索／读取受有限轮数和用户设置的共享每日请求额度约束。多用户隔离尚未接入。
