# 含附件的对话复制

阶段 4 第 5 项的独立复制检查点。管理菜单复制完整对话；消息的「复制到新对话」复制所选父链及其历史摘要。副本使用独立 URL、消息 ID、附件 ID 和私有 R2 键，不发起模型调用。

## 文件和引用

完整复制纳入捕获时已保存的全部原文件，包括尚未用于消息的文件；尚未保存完成的上传不进入副本。指定消息复制只纳入该路径及摘要所需的消息与文件，不包含旁支、后续消息和未引用文件。正文、供应商返回的思考内容、模型信息、会话参数、生成报告和摘要覆盖关系沿用现有复制规则；生成中的回答只复制已保存前缀并标记未完成。

原文件以流转发到新的 R2 键，验证长度、类型与 SHA-256；已保存的文本／CSV／PDF 提取结果也独立保存和校验。消息引用只重映射附件 ID，保留不可变哈希、解析版本和预算。副本在源对话删除后仍可下载、私有预览和问答；副本删除不撤销源文件。被副本消息或活动任务使用的文件仍不能独立删除。未解析原文件继续作为原文件保存，不因复制自动变成问答资料。

## 请求、发布和中断

复制 POST 使用 `{ requestId }`，该 UUID 同时作为目标对话 ID；服务端将它绑定到源对话及可选消息 ID。同一请求在当前实例共享正在执行的复制，完成后直接返回同一副本，不增加文件写入；用于其他来源的同一 ID 明确拒绝，已删除的 ID 不重新创建。

浏览器在发请求前保存标识。网络失败、响应丢失或 20 秒等待超时后，重试沿用标识；刷新或关页后重开也可继续查询。明确的输入错误或已停止结果会清除当前标识，下一次主动复制使用新的请求。退出并清除本地记录会清除这些标识，较晚返回的请求不会重新写入缓存或切换页面。切换对话保留目的页面和草稿。

Library 在写入文件前持久化元数据登记，副本在文件、解析文本、引用与消息全部保存后才出现在对话列表并可经公开 API 读取。复制 Promise 使用 DO `waitUntil`，支持发起页面关闭后继续；这不保证实例故障后恢复同一执行。Cloudflare 当前说明该方法可防止驱逐直到 Promise 完成或最多 15 分钟，应用另设 10 分钟期限。[DO State](https://developers.cloudflare.com/durable-objects/api/state/)

超时、源／目标删除或失败会停止后续步骤，将未完成副本交给持久化删除和 Alarm 清理。实例重置后，已认领但没有当前执行的复制明确失败，不自动重新写文件。已开始但结果未知的 R2 写入仍受原文件租约及清理规则约束；容量预留在确认删除前保留。当前输入和源对话不会因普通复制失败被清空。

## 原型资源边界

同时最多 2 项复制；元数据登记最多 1,000 项，开始新请求时回收超过 7 天的终态记录。登记只存 ID、来源、状态、期限和错误，不存消息正文、密钥或文件内容。删除标记与已有对话 ID 仍防止旧 ID 被重新创建。

每个原文件沿用 5 MiB 限制、每对话 64 个／32 MiB、每空间 512 个／512 MiB，以及 UTC 每日 100 次文件写入尝试。复制产生新的容量占用及读写操作，失败不退还写入尝试；达到额度后明确停止和清理。包含文件的独立复制不会免费消除 R2 或 DO 用量。

消息和配置的复制负载最多 12 MiB。大历史通过原生 RPC 流传给 DO 解析与恢复，返回快照也使用流封装，普通 Worker 不解析这些大 JSON。恢复事件按约 1 MB 分批写入，同一事务保存全部消息，避免超过 SQLite 单个字符串、BLOB 或行的 2 MB 限制。[DO 限制](https://developers.cloudflare.com/durable-objects/platform/limits/)

本地回归使用原生模拟 DO／R2、实际供应商 SDK 与模拟响应，不部署、创建远程资源或调用付费模型；它不证明真实 Cloudflare CPU、免费余量或账单。含文件的可恢复备份仍在阶段 4 第 5 项的下一检查点实现，当前 JSON 备份继续明确拒绝附件，文本导出保留文件名。

## 验证

199 项单元测试、应用／Worker／工具类型检查、测试文件的独立严格 TypeScript 检查及生产构建通过。主浏览器套件 180 项分批验证：完整运行 179 项通过，唯一失败来自文档解析测试误加了复制请求参数；恢复空请求后，全部 14 项文档场景通过。新增 8 项附件复制场景及已有 7 项复制场景的专项回归也全部通过；生产 PWA 回归 2 项通过。
