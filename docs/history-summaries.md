# 历史摘要与自动压缩

阶段 3 的历史压缩功能。对话右上角的「压缩历史」允许选择摘要模型和覆盖到哪条已完成回答；默认留出最近一个完整轮次。摘要调用前显示额外模型费用提示及近似输入、输出预算。摘要原文使用 Markdown 流式展示，完成后可以展开查看、重新生成或删除；「会话参数 → 使用历史摘要」控制后续回答是否使用它。

## 自动压缩

「会话参数 → 自动压缩历史」默认关闭，开启处明确提示额外供应商模型费用。默认阈值为可用输入预算的 80%，可调整为 50–95%；可指定摘要模型，留空使用本次回答模型。设置沿用自动保存、离线草稿、跨设备同步、复制和备份。关闭「使用历史摘要」也会关闭自动压缩。

每次发送，云端先估算已有摘要、未覆盖的完整当前父链、系统提示词、本次输入和协议开销。阈值基于可用输入预算，已经扣除输出预留和安全余量；「最近历史消息条数」只限制压缩后发送的原文，不提前隐藏自动压缩所需评估的历史。达到阈值时，优先覆盖到倒数第二个已完成回答，保留最近完整轮次；已有摘要后仅有一个新轮次时可以覆盖该轮次。覆盖必须前进，不重复压缩相同边界，不借用旁支摘要。

接受请求时，一次事务保存独立的摘要任务、等待中的回答任务和两者依赖；固定摘要输入及模型、回答模型及参数、父链、当前问题和上下文策略，随后设置 Alarm。摘要输入必须完整装入所选模型窗口；模型不可用、固定输入超预算或资源限额拒绝时，不创建任务或调用模型。

只有完整摘要的正文和覆盖元数据保存后，同一事务才构建回答的最终上下文、保存估算并解除依赖。下一个 Alarm 调用已接受的回答模型，避免一个事件连续承担两次供应商等待。浏览器显示「等待历史摘要」，客户端关闭也能完成两步；刷新、另一设备读取和重复请求不会新增模型调用。此有限两步任务复用 DO 执行器，不增加 Workflow。

压缩后仍超预算或无法装下所要求的完整原文尾部时，回答失败并明确提示调整预算／手动压缩；不静默省略额外历史、不循环压缩或重复付费。当前输入和系统提示词无法通过摘要缩短。无可继续压缩的完整历史且原文尾部无法容纳时，在接受前报错。

## 持久化与分支

摘要是有 `summary` 元数据的独立助手记录，保存完整父链消息 ID 和覆盖边界。接受任务时一次事务保存覆盖范围、完整输入、独立模型配置、估算和请求 ID，再由既有 DO＋Alarm 执行器调用模型。不会增加伪造的用户提问，不改变聊天分支或草稿，也不依赖浏览器继续在线。

只有已完成、非空、未删除且未被输出上限截断的摘要可以使用。覆盖范围必须逐 ID 匹配当前父链前缀；选覆盖最远的摘要，同一边界选较新的完成版本。编辑消息产生的新分支不会继承路径不同的摘要。旁支内容、思考通道、失败回答和已删除内容不进入摘要输入。

生成更远边界的摘要时，可使用严格更早边界的有效摘要和未覆盖原文；重新生成同一边界不会把被替换的摘要当作全部输入。输入必须完整装入摘要模型窗口，不能为使调用成功而静默省略待压缩内容。超限时在创建任务、消息或调用模型前报错，用户可选更大窗口、更早边界或先压缩较早前缀。

## 后续回答与预算

摘要作为带历史资料标记的用户消息放在未覆盖原文前面，不作为系统提示词。会话系统提示词和本次问题保持各自角色。云端决定最终上下文；客户端只预览估算。

摘要文本、资料标记和消息封装全部计入输入预算。估算与生成信息记录摘要 ID、近似 Tokens、覆盖条数以及未覆盖历史的省略数量。输出预留仍不设置普通聊天请求的输出上限。摘要任务单独设最多 `min(2048, 模型最大输出, floor(窗口/4))` Tokens（最小 1），使用专用压缩提示词，不继承聊天的系统提示词、采样参数或输出上限；不展示思考内容。只有模型明确支持 `none` 时使用此思维强度，不能据此承诺所有模型都没有内部思考费用。

关闭「使用历史摘要」后按原始父链重新构建上下文，原文仍可能受预算或条数限制而省略。摘要生成具有信息损失的可能，用户可查看结果、重新生成或停用；仅在明确开启自动压缩后才可能额外调用摘要模型。

## 失败、停止与重复提交

部分、失败、取消、空白、过长或 `length` 截断的摘要保持可查看状态，但不用于后续上下文。压缩失败保留原始消息；重新生成必须由用户明确发起新的请求。不自动重复模型调用。

网络结果未知时，已有待发送队列携带同一请求 ID 重试；服务端返回已经接受的任务，包括后来被禁用的原模型。刷新、第二设备读取或 Alarm 重入不再次调用供应商。停止使用既有持久化取消与上游终止路径；已产生的费用仍由供应商决定。

自动摘要失败、中断、输出截断或保存失败时，等待中的回答也结束且不调用回答模型。摘要期间停止任一任务会持久化取消两项任务；回答已解除依赖后沿用普通回答停止流程。DO 重置无法恢复已经断开的供应商连接：进行中的摘要保留已保存部分并失败，回答不会启动；完整摘要已保存且回答尚未启动时，新的实例只执行那项已接受回答。用户主动重试使用新请求 ID，不自动续费。

## 删除、复制与备份

删除来源消息时，同事务清空所有覆盖该消息的摘要正文、生成报告和相关旧事件，并标记摘要失效。原始父链标识保留用于图结构；不存在通过摘要把已删除原文重新带入上下文的路径。只删除摘要不会删除它的来源消息。

全文搜索只索引普通消息，避免同一事实因摘要重复命中。完整复制和备份包含摘要；从指定消息复制时，只携带覆盖范围包含于所选父链的摘要。副本重建消息 ID、覆盖 ID 和生成报告的摘要引用，不自动启动压缩。进行中的摘要备份为可恢复查看的失败部分，导入后不会自动续费调用。

每个对话最多 20 条未删除摘要，同时受已有 1,000 条记录、4 MiB 历史接受任务预算及 SQLite 边界约束。摘要正文最多 20,000 字；删除旧摘要可释放摘要数量配额，保留的墓碑仍计入消息数量。这里是应用限额，不是 Cloudflare 的平台额度。

## 验证范围

使用本地模拟供应商验证父链隔离、完整输入检查、用量保存、跨设备读取、页面关闭后后台完成、重复请求、停止、失败、复制和备份，以及自动摘要保存后启动回答的顺序。模拟摘要仅用于验证信息传递，不证明真实模型摘要质量；也不以本地经过时间推断 Workers Free CPU 或费用。
