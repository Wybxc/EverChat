# 前端设计规范与核查

日期：2026-10-18。适用当前 shadcn/ui、Radix、Tailwind 和 EverChat 语义主题。规则承接[紧凑布局](../plans/frontend-compact-layout-plan.md)和[消息原位编辑](../plans/message-editing-density-plan.md)，本文件作为现行核查入口。

## 规则

常用操作直接可达，低频配置折叠；状态、错误、焦点和关闭入口不能随折叠消失。文案只用于导航、状态、必要指示和会影响决定的费用信息，不增加装饰性解释。

| 项目       | 规则与实现                                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 控件       | 鼠标次级按钮、Tab、菜单、命令项、侧栏导航、供应商行、模型启用区域共用 `--control-target: max(2rem, 32px)`；触屏或不超过 40rem 的窄屏为 `max(2.75rem, 44px)`      |
| 间距       | 同组图标 `--space-actions: .125rem`；相关项 `.5rem`；字段 `.75rem`；任务组 `1rem`。使用已有 Tailwind 对应刻度，跨组件重复规则用 CSS Token                        |
| 单位       | 字号、行高、间距、圆角、内容上限主要用 rem；布局用 flex／grid、百分比和视口可用空间；1px 分隔、焦点描边及物理点击下限用 CSS px。安全区用 `env()`，不固定设备高度 |
| 排版       | 沿用系统字体、正文和 Markdown 行距；工具栏压缩不缩小正文。触屏输入至少 16 CSS px，允许用户页面缩放；长名称截断保留可访问名称                                     |
| 颜色       | 只使用 background、foreground、muted、primary、accent、destructive 等语义色；浅／深色分别验证。普通文字目标 4.5:1，焦点和必要控件边界 3:1                        |
| 边界       | 一个接缝只画必要的一层线；模型列表使用行分隔，展开编辑器使用轻背景。输入和浮层保留边界；不通过多层卡片制造层级                                                   |
| 菜单       | 同组操作使用统一图标规则，次组靠标题／单条分隔；删除等危险项维持 destructive 前景。浮层使用不透明 popover 表面，避免下层文字影响对比度                           |
| 状态与焦点 | hover、focus-visible、disabled、保存中和失败可区分。错误不藏入菜单；模态约束焦点并在关闭后返回触发位置；拖入附件不抢焦点，切换对话取消迟到上传                   |

尺寸参考 [Carbon Button](https://carbondesignsystem.com/components/button/style/)、间距原则参考 [Fluent Layout](https://fluent2.microsoft.design/layout)、原位编辑参考 [Atlassian Inline edit](https://atlassian.design/patterns/inline-edit/)。32／44px 是本项目的选择；[WCAG 2.2 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)的常规最低要求为 24px，不能把图标绘制尺寸当作点击尺寸。

## 区域核查与整改

| 区域         | 核查结论与本轮处理                                                                                                                       | 保留的空间及原因                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 侧栏         | 对话行跟随统一目标；桌面收紧垂直内边距，保留当前选中、生成状态、菜单和长标题截断；键盘焦点约束继续通过回归                               | 新建对话主入口及顶部导航保持较大尺寸                       |
| 消息／编辑   | 原位编辑与同组操作 2px 间隔沿用；提问与回答的编辑均在顶层，分支切换、生成概览、失败和取消／保存可见                                      | 开放式回答、代码和数学公式不压缩阅读行距                   |
| 输入区       | 保持单层外框、单行工具区与响应式折叠；拖放覆盖层不参与布局，也不遮挡点击                                                                 | 输入、发送／停止保持 44px，避免高频主操作误触              |
| 模型选择     | 命令项沿用统一目标，键盘搜索和相同显示名模型身份保持；触屏字号回归                                                                       | 搜索输入保留表单高度，不为多显示一项而缩小字号             |
| 供应商／模型 | 供应商行移除固定 44px 覆盖；模型启用行、铅笔按钮跟随鼠标／触屏目标，收紧行内边距；连接字段 12px，结构网格 12px。大量模型仅展开一个编辑器 | ID／显示名两行时可超过最低行高；密钥、端点等输入仍 44px    |
| 设置         | Tab、复选／开关标签、折叠标题统一目标；Tab 水平内边距缩短；移除滚动区底部空隙，避免列表透出保存状态栏下方。固定关闭按钮与主体独立滚动    | 移动端保留 44px 目标、安全区及横向 Tab 导航                |
| 搜索         | 沿用设置式弹窗、固定关闭、独立结果滚动、触屏 16px 输入；无额外说明段落                                                                   | 软键盘、横屏及真实 iOS 结果沿用先前验收，本轮仅浏览器回归  |
| 菜单         | 移除共享组件强制 accent 前景覆盖，恢复危险项语义色；取消透明／模糊表面，按视口可用高度滚动                                               | 保留浅边界和阴影以区分上下层，不能用少边框原则消除浮层边界 |
| 弹窗／预览   | 对齐统一任务组间距；长文件预览和表单内部滚动，主操作与关闭入口可达；模态期间不接受背景文件拖入                                           | 删除确认保留明确任务说明和独立动作组                       |

列表、菜单和折叠入口的最低尺寸不是固定高度；长标签、两行模型名或 200% 字号可撑开。输入框、主操作和阅读导航的 44px 属于明确例外，不能被全局紧凑规则覆盖。触控笔记本按 `any-pointer: coarse` 采用触屏下限。

## 验收

Chromium 覆盖 320／360／390／768／1024／1280／1440px 及 844×390 横屏，浅／深色、200% 字号、长名称、富文本横向滚动、输入工具区、菜单、分支操作、原位编辑和焦点；供应商回归检查 320 个模型、32px 桌面铅笔按钮和 44px 移动启用区域。截图覆盖 390px／1280px 聊天和桌面／移动供应商面板。
