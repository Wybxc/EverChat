# 运行架构与数据流

[文档索引](../README.md) · [模块职责](modules.md) · [开发指南](../development.md)

本页承接项目首页移出的实现细节。具体保护数值统一见[免费层资源政策](free-tier-resource-policy.md)，历次性能结论和复现条件见[测量入口](../measurements/README.md)。

## 服务职责

| 组件            | 职责                                                  |
| --------------- | ----------------------------------------------------- |
| React／PWA      | 路由、草稿、离线待发送、流式解析与渲染、本机缓存      |
| HTTP Worker     | 静态资源路由、Access JWT 验证、同源检查、API 转发     |
| Library DO      | 个人对话索引、供应商、预设、搜索、附件登记与清理协调  |
| Conversation DO | 每对话消息与版本、任务、检查点、Alarm、WebSocket 同步 |
| UsageStore DO   | 调用事实、当次价格及费用聚合                          |
| ShareStore DO   | 只读快照、令牌验证、过期与删除清理                    |
| WebToolWorkflow | 联网任务的模型与工具步骤编排，调用状态由 DO 持久化    |
| 私有 R2         | 原文件和派生文本；由鉴权接口提供访问                  |

当前不使用 D1。多个获准身份共享同一空间，尚未接入多用户数据隔离。

```text
浏览器 ── 静态页面／SW ── 静态资源
  │
  ├── 私有 API／WebSocket ── Access ── Worker 验证 ── Library／Conversation
  │                                                     │
  │                                      原子保存输入、配置、任务与 Alarm
  │                                                     │
  │                                      Alarm ── 模型供应商／工具编排
  │                                                     │
  └────────────────── 在线预览与已保存状态 ◀──────────────┘

匿名分享 ── /public/shares/:id + 令牌 ── Worker ── ShareStore
```

## 接受任务与后台执行

提交在同一存储事务中保存输入、配置快照、请求身份、任务 outbox 和 Alarm，成功后才确认接受。浏览器保留 request ID，网络结果未知时用原 ID 重试。每个对话只允许一个活跃生成，不同对话可同时运行；后台任务不依赖浏览器保持连接。

模型调用前持久化认领，供应商自动重试为零。用户重新生成或编辑提问会创建新版本，不能用重复付费调用掩盖任务恢复。已经接受的供应商、模型、提示词、思维强度和工具配置不随后续设置变化。

普通生成由 Conversation Alarm 执行，保留 14 分钟供应商期限和 15 分钟看门狗。联网工具使用 Workflow 编排，不设固定工具总轮数，仍受任务时间、每轮调用数量、上下文及联网服务额度保护。模型通过 AI SDK 对应适配器调用，OpenAI 请求设置 `store: false`；DeepSeek 使用兼容协议并映射其思考参数。

## 分层流处理与保存

统一应用事件字节约每 100ms 或达到 8 KiB 形成在线预览，约每 1.5 秒或达到 32 KiB 提交一次。单次提交和订阅确认窗口均有界，下一次读取上游前等待必要的存储提交。缓慢订阅者断开后重新同步，不阻塞保存或其他客户端。

服务端使用对应 AI SDK 的 `doStream()` 解析一次供应商响应，转为 `events-v1` 正文／思考增量或替换、用量、结束事件。客户端及时解析预览并渲染；服务端批量追加规范正文块，保存应用事件中未完成 JSON／UTF-8 的检查点。供应商原始流、签名和加密状态不进入浏览器。工具私有续接资料在同一次解析中收集，轮次完成时保存结构化记录，不保存或回放原始字节。完成时原子保存正文、思考、状态和已验证用量，清理检查点与任务上下文。

预览不等于持久化确认。客户端分别维护实时视图和已保存快照，只有后者进入持久缓存、导出和重连基线；预览尚未保存时显示「保存中」。缓存合并写入，完成、切换对话或页面隐藏时及时刷新。

字节偏移和微批次序号用于检查重复与缺口；字节以 base64 进入同步帧，可在 UTF-8 或应用 JSON 中间切分。浏览器和云端复用应用事件解码；只有服务端识别供应商协议，不依赖客户端上报终态用量。

大快照和模型目录由所属 DO 构造原生 JSON Response，经 RPC 转发；HTTP Worker 避免再次反序列化与编码大段内容。这降低普通请求路径的 CPU 压力，不取消 DO、SQL、内存或账户资源边界。

## 状态同步与本地缓存

同步采用 `seq/epoch` 和对象最新修改版本，不保存逐次通知历史。新客户端通过分页基线重建消息，重连取最新状态差分；版本失配或差分过大时重新读取基线，随后补充当前在线尾部。无法靠某条旧通知重建完整状态，也不要求离线客户端逐事件追赶。

客户端快照、草稿、待发送请求和检查点优先存入 IndexedDB，保留 localStorage 故障回退。缓存只属于该浏览器，不授予联网权限；登录、归属检查与退出 epoch 控制其读取。API、认证响应和附件原文不进入 Service Worker 静态缓存。

PWA 必需预缓存只包含启动页及其静态依赖、样式和图标；Markdown、公式字体、图表、代码高亮和 PDF 模块按需缓存。更新或修复缓存前协调所有标签页保存草稿和检查点；未保存设置、上传或结果未知的写请求阻止重载。下载失败继续使用原版本，缓存修复不清除聊天及待发送请求。

## 消息内容、分支与删除

消息对外以 `parts` 传递正文、思考、图片及文件引用。正文和思考各自汇总为一个非空通道，思考在正文前；这不是原始 SSE 的交错事件列表。工具过程另记录思考位置以恢复执行顺序。普通历史上下文、复制文本和引用使用正文，搜索与导出可包含思考。

版本通过消息父链与修订关系表达，界面只显示选定路径。对话 URL 为 `/c/:id`，分支位置使用 `?branch=:messageId`；浏览位置保存在本机，远端版本与迟到响应不抢占阅读。发送显式指定当前路径的父节点，没有“全局最新消息”回退。普通上下文排除旁支、已删除内容与思考通道，按预算选择完整轮次和适用摘要。

整段复制重建消息与附件身份，路径复制只保留选定父链；私有文件也独立复制。备份保存规范内容及关系，不保存密钥、实时游标和运行任务。当前维护现行协议与备份结构，不提供旧格式在线转换。

单条删除清空内容和结果元数据，保留父链、删除标记及必要的请求去重，搜索通过持久化 outbox 更新。整段删除先在 Library 保存标记，再取消任务、清空对话存储并整理索引；清理由 Alarm 有界重试。删除游标同步到其他设备，阻止旧缓存和迟到请求恢复已删除数据。删除标记仍占少量存储，SQLite 文件分配空间也不一定立即收缩。

## 中断、取消与容量错误

停止先持久化取消意图，再终止上游、保存可解析尾部并提交终态。供应商是否及时停止计费由其服务决定。DO 实例重置或上游断线不能恢复同一次 Token 生成，保留已存内容并明确中断，不自动重新调用模型。

供应商断流且已有可靠正文时，将部分回答封存为正式版本并标记 `generation.interrupted`，后续上下文可以携带正文；只有思考、摘要失败、主动停止及无法可靠保存的情况分别处理。中断不伪装成成功完成，不触发成功通知或自动标题。

容量不足返回明确错误，不自动删除历史、静默截断原文或重试模型。写入失败保留最近检查点；无法可靠写入终态时不发布完成确认。资源数值、SQL 行预算、工具续接和附件限制集中见[资源政策](free-tier-resource-policy.md)，存量结构调整只用[离线运维流程](../operations/offline-storage-migration.md)。

## 安全与公开读取

Access 保护 `/api`、`/api/*`、`/auth`、`/auth/*`，Worker 再验证 JWT 与允许身份。WebSocket 在令牌到期或订阅租期后重新握手，不为每个增量查询身份。密钥保存在 Library 和已接受任务的私有配置；显式查看时仅进入设置组件内存，不进入离线缓存、导出或备份。

公开分享页面从 URL 片段取出令牌，以 Authorization 头请求同域 `/public/shares/:id`。服务端逐次校验令牌、状态和有效期，一次响应返回完整快照；公开读取不写浏览日志、不延期、不创建长连接。分享令牌哈希用于验证，可再次复制的令牌由部署 Secret 加密保存。到期立即拒绝读取，Alarm 回收正文；删除链接无法撤回接收者自行保存的副本。

退出先清除本机记录，再进入 Access 退出流程；离线退出保持锁定，联网后完成远端退出。身份或权限变化不能由缓存绕过。
