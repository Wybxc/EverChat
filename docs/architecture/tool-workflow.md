# 有限工具任务的 DO／Workflow 执行与展示

阶段 5 的执行基础。Conversation DO 已接入逐轮模型流、工具认领、公共过程同步和页面展示，Workflow 负责有限的“模型 → 工具 → 模型”编排。[联网服务](../features/web-tool-service.md)提供 Tavily 搜索／网页读取、共享每日请求上限、网页配置及默认关闭的会话开关。完整执行与网页入口通过隔离本地运行时和模拟服务验证；功能范围见[路线图](../plans/serverless-feature-roadmap.md#阶段-5联网搜索与网页读取)。

## 执行与持久化

1. 接受消息时，同一事务保存请求指纹、固定模型配置、初始工具选择和公共过程，再设置 Alarm。重复请求返回原消息及首轮运行 ID；冲突请求拒绝。模型工具能力明确不支持时拒绝；未知或别名推断允许用户主动尝试，新对话仍默认关闭工具。
2. Alarm 在上下文就绪后创建根任务及 Workflow 派发记录。自动摘要仍先使用普通 DO 执行，摘要保存后才初始化工具任务及其十分钟期限；摘要失败或取消时，同一事务结束依赖回答及其公开工具状态，不创建 Workflow。
3. Workflow 实例 ID 同时包含对话和请求 ID；不同对话使用相同请求 ID 不会共享编排。创建响应丢失时查询已有实例，不重启已经存在的 Workflow；创建失败按退避重试并受根任务期限约束。
4. Workflow 登记模型步骤许可，DO 原子认领先落盘，再连接供应商。每轮有独立运行 ID、字节偏移和流解析状态，但属于同一条助手消息；前一轮已保存的正文和思考作为下一轮前缀。
5. 模型轮次完整保存后，DO 写入工具参数和通知引用。Workflow 通过持久化事件等待，再读取 DO 的权威状态；每个工具先认领并保存运行状态，结果／错误保存后才登记下一次模型请求。

Workflow 步骤只返回状态、轮次和调用／任务引用，不保存密钥、模型正文、工具结果或私有续接载荷。RPC 步骤最多重试两次，间隔一秒、指数退避，每次尝试重新获取 DO stub；DO 重置后旧 stub 的后续 RPC 都可能失败，不能跨步骤复用。[Cloudflare stub 语义](https://developers.cloudflare.com/durable-objects/api/stub/)

模型与工具的认领由 DO 日志去重，Workflow 重试只重新查询或认领已有步骤。模型连接中断后明确失败，工具认领后未保存结果则在实例恢复时保存中断错误；两者都不会自动重新发起未知的外部请求。已保存的工具错误可以作为原生工具结果交给下一轮模型。

## 公开流与私有续接

工具响应中的签名、加密推理项目和 redacted thinking 只供服务端续接，不进入公开流或浏览器解析检查点。

普通聊天和工具模型共用一次实时 SDK 解析，分别处理公开事件与私有续接：

- `ProviderToolCollector` 在实时 SDK 解析中收集并验证私有续接；完成时保存结构化轮次，不存供应商原始流。
- 正文、可见思考、用量和结束状态转换为 `events-v1` 应用事件发送给客户端；低频提交到 `message_content_chunks` 与 `generation_checkpoints`，不保存完整事件流。公开帧、快照、缓存和备份不包含原始工具参数事件或供应商私有资料。

正文和思考继续流式 Markdown 渲染。每轮完成／失败／取消时，在同一事务压实公开前缀并保存消息和工具状态；根任务终态清理所有私有续接及固定配置。公开调用参数、状态、来源及错误按低频状态变更同步。

普通聊天与工具模型共用实时 SDK 解析及统一应用事件，原始字节日志和 EOF 回放已移除。SDK 解析增加服务端 CPU，删除私有原始流减少 SQL 和重复解析；**需要新的真实平台测量，不能据本地结果保证 Workers Free 费用**。模型正文及工具结果不经过 Workflow 步骤存储。

## 停止、恢复与预算

| 边界       | 当前策略                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------- |
| 根任务期限 | 上下文就绪、初始化后 10 分钟                                                             |
| 模型调用   | 不设固定总轮数，受任务期限和上下文预算保护                                               |
| 工具调用   | 每轮最多 2 次；单次最多 15 秒取消信号                                                    |
| 单个流事件 | 最多 1 MiB                                                                               |
| 私有续接   | 每轮最多 1 MiB，根任务终态清理                                                           |
| 结果       | 每次最多 64 KiB、5 个来源，来源正文合计 12,000 字符                                      |
| 跨轮文字   | 正文、思考合计最多 768 KiB JSON 转义字节                                                 |
| 下一轮输入 | 初始上下文＋2,048 个工具定义预留 Token＋已保存私有内容／结果的近似估算，不得超过固定预算 |

停止请求接受任意已知轮次的运行 ID，映射到助手当前轮次，持久化取消状态并终止模型／工具；已保存的前缀和结果保留，不再登记下一步。超时与上下文不足都有明确终态。DO 重置会先恢复检查点，再提供快照；未认领步骤仍可继续，已认领模型不重发，未保存工具结果明确标记中断。

通知是唤醒提示，不能替代持久化状态。事件使用 `model-N` 类型，在创建实例后投递；失败按 5、10、20、30 秒退避，有效期至根任务截止后一分钟。终态实例确认后清理待发送通知。没有活跃任务、通知或搜索同步工作时，不周期性唤醒 DO；等待工具／Workflow 许可的模型也不按秒轮询。[Workflow 事件](https://developers.cloudflare.com/workflows/build/events-and-parameters/)、[实例 API](https://developers.cloudflare.com/workflows/build/workers-api/)

删除消息会擦除公开工具过程与任务日志，迟到编排查询返回已取消；删除对话会中止在途模型／工具并保存删除标记。已在 Workflow 等待的引用可能保留到事件或最多十一分钟等待超时，不能因此重新调用模型或重建已删除内容。

## 页面、复制与备份

助手消息显示可折叠的工具过程：查询／网页地址、执行状态、结果／错误及可打开的来源链接。页面关闭不取消任务，第二设备重连读取已保存过程。工具结果显示为纯文本，外部链接使用公开 HTTPS 校验、无 opener 和无 referrer。

用量按每轮实际供应商报告累计；有些轮次未返回的字段只累计已报告部分，并将整体标为“部分报告”，不能把缺失值当成已确认的零。未完成／溢出的计数也明确为部分报告。排队从第一次认领计，首 Token 从第一次模型连接起算到首段正文或思考；总用时涵盖首轮开始、工具等待和后续模型轮次。消息中的上下文估算更新到最后实际登记的模型轮次，包含工具定义、先前助手内容及结果，并单列工具占用；它仍是近似保护，不能作为账单。

独立复制和可恢复备份保留公开工具过程，不复制运行许可或私有续接，不恢复执行。生成中的备份将消息和任务标为失败、未完成调用标为取消，保留已经保存的结果。导入严格验证调用身份、结果对应、轮数、状态和来源，拒绝额外私有字段；删除后的消息不导出工具内容。

## 验证范围

单元覆盖公开／私有流分离、分片 UTF-8 与大签名、跨轮前缀、私有回放边界、用量累计、备份验证与擦除事务。原生 Workflow 场景覆盖四协议完整交换、无在线客户端、跨对话相同请求 ID、创建响应丢失、事件投递失败、DO 重置、停止／超时／预算、页面关闭及跨设备、缓存与帧隐私、复制／备份和单条删除；自动摘要另覆盖成功后继续工具交换，以及失败／取消后跳过回答并保留有效备份。

本检查点通过 260 项单元测试、应用／Worker／工具类型检查、测试与 fixture 的独立严格类型检查、生产构建和 2 项生产 PWA 回归。完整浏览器套件首轮 220 项中 219 项通过；滚动场景等待生成结束时遇到系统睡眠，追踪帧间隔约 985 秒，与 macOS 记录的 986 秒睡眠吻合。该场景保持原断言单独连续运行三次，均在约 27 秒内通过；其余浏览器场景无需改动或重试。新增的 16 项原生 Workflow 场景和 3 项自动摘要依赖场景均在完整套件中通过。

所有外部响应均为模拟，未部署或创建远程资源，也没有实际模型、搜索或网页调用。这些结果不证明实际服务质量、真实供应商全部组合或 Cloudflare 免费层资源消耗。
