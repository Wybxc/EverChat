# 供应商流解析迁移到 AI SDK

更新日期：2026-10-20。状态：已实施，完成本地验收；真实平台资源测量另行验收。

## 目标与边界

由匹配协议的 AI SDK provider 的 `doStream()` 解析真实响应，移除普通聊天绕过 SDK 解析、联网轮次再次回放解析，以及浏览器识别四种供应商协议的实现。保留 EverChat 的低频批量持久化、多端预览与恢复、取消、部分回答保留、工具校验、用量统计和诊断。

不增加自动重试、工具轮数限制或真实模型测试费用。不在访问请求中迁移历史数据。已完成消息继续使用既有正文、思考和生成信息；传输协议更新需显式版本化，发布前检查旧版进行中的任务，必要时通过本地运维停机整理。

## 调研结论

- OpenAI 官方 Responses 使用 `@ai-sdk/openai`；第三方 Responses 使用 `@ai-sdk/open-responses`。通用 Chat Completions 使用 `@ai-sdk/openai-compatible`，Anthropic、Gemini 使用各自 provider。
- 本地模拟确认 Open Responses 可以流式解析完整思考和摘要、回传工具续接所需的明文思考和加密状态；同时收到两个思考渠道时仍需去重。
- SDK `error` 可能是流事件，且其后仍可能出现 `finish: stop`。错误必须不可被后续成功事件覆盖。缺失终态、内容过滤、供应商错误和主动取消需分别判断。
- SDK 内部解析状态不适合作为应用检查点。SDK 只在服务端处理一次供应商响应，对客户端输出允许公开的统一事件；应用状态可以独立保存和恢复。
- 最终用量采用 SDK 统一字段及必要原始计数；提前断流时保留已报告计数。原始事件、错误回显、签名和加密状态不发往浏览器。

## 实施顺序

1. **统一事件与状态**：定义协议无关的正文／思考增量与替换、用量、结束事件；保持字节分批、序号、确认、检查点、容量保护及 UTF-8 边界恢复。结束原因同时保留标准分类和原始值。
2. **SDK 实时解析**：增加 Open Responses 适配器，使用自定义 fetch 保留 HTTP 正文诊断、脱敏、类型检查、取消和请求入账。对原始输入仅做必要的流边界、大小及完成标记保护。由统一适配层处理思考去重、早期用量及终态校验。
3. **统一普通与工具生成**：普通回答、首 Token 测量、标题生成、摘要改用统一事件。工具轮次在同一次 SDK 消费中建立私有续接记录，继续校验工具身份、参数、签名和调用权限；移除供应商响应的重复解析与伪造 Chat Completions 展示流。
4. **回归与清理**：替换依赖手写供应商解码的测试；保留跨字节、重连、部分回答、工具交错、错误脱敏、用量入账和低频写入等行为测试。更新文档并删除无用实现。
5. **交付**：通过类型检查、单元／原生集成测试、构建及相关浏览器测试与本地资源测量后提交推送；记录真实平台验证的证据边界。生产数据库只在需要时通过现有本地运维工具处理，禁止在线迁移。

## 验收条件

- 四种协议及 OpenAI／兼容 Chat 的正文与思考正确流式显示；Responses 完整思考优先于摘要，不重复追加 done 事件。
- HTTP 和流中错误保留脱敏后的供应商原因、状态及响应正文；原始结束原因可诊断，解析错误不被最终 stop 覆盖。
- 中断前的有用回答保留为历史上下文；取消不重试供应商；不完整工具调用不得执行。
- 工具执行顺序和思考位置一致；明文、签名和加密续接状态正确往返且只保留在服务端。
- 正常及中断用量不丢失，缓存与思考计数、各轮汇总不重复计费。
- 多端预览、确认、断线恢复和最终快照一致；仍沿用批量提交，不逐 Token 写数据库，不保存供应商完整原始流。
- 所有必要测试通过；本地测量单独标记，不能据此宣称 Cloudflare Free 平台 CPU 或费用已验收。

## 追加：让历史压缩过程透明

移除「使用历史摘要」界面选项和上下文条件开关。有效摘要始终用于其匹配分支的后续请求，原始历史保留回看；失败、未完成、空白或截断摘要不替代原文。摘要在覆盖边界之后以分割线和直接展开的消息显示，包含正文、覆盖范围、生成状态和当前是否使用。多份摘要继续按覆盖最远、同边界最新完成版本选择。

公开设置仅返回当前字段，不在请求处理中改写历史数据库；已废弃字段和旧私有流表只通过本地离线运维转换清理。发布前必须确认旧版 `raw-sse-v1` 进行中任务已完成或停止，禁止将旧原始事件交给新解码器。

## 追加：输入框历史切换

空输入框用上／下方向键切换当前可见分支中已发送的用户提问；调出的文本未经编辑时可以连续切换，向下越过最新一条回到空框。用户输入或修改文字后，即使撤销回原文也不再接管方向键，直到清空输入框。输入法组合输入、修饰键和文本选择仍使用原有编辑行为。切换只复制文字，不修改历史消息或重复附加文件。

## 执行结果

四协议实时 SDK 解析、公开事件、私有结构化续接、用量和错误处理已落地；透明摘要和方向键历史追加需求也已完成。单元、原生离线运维、相关浏览器回归及普通／工具流本地测量均通过，详见[执行与测量记录](../measurements/provider-sdk-streaming-2026-10-20.md)。未发起真实供应商调用，未将本地墙钟或 SQL 计数解释为 Cloudflare CPU／账单；线上旧字段与表没有在请求中迁移。
