# 联网搜索与网页读取服务

阶段 5 的联网功能。明确配置 Tavily 后，Conversation DO 可执行 `web_search` 和 `read_webpage`，Workflow 编排有限的模型与工具轮次。工具过程展示来源链接，模型工具定义要求在回答中引用来源。网页设置、独立会话开关和后台执行均已接入，并使用隔离本地运行时与模拟上游验证。

DeepSeek Search／Fetch 的后续接入见[计划](../plans/deepseek-web-tools-plan.md)（2026-10-18，尚未实施）；本篇仍说明当前 Tavily 服务。

## 网页使用

1. 打开空间设置的「联网」Tab，填写 Tavily API 密钥和每日请求上限。修改自动保存，失败保留当前编辑并提供重试；页面显示今日已用次数，可手动刷新。
2. 选择模型，点击聊天框「联网」或右上角「会话参数」，分别开启「联网搜索」和「网页读取」。新对话默认关闭；未知能力允许用户主动尝试，明确不支持或缺少服务密钥时不能新增启用项，但仍能关闭原有选择。参数内可直接打开服务设置，配置后返回原参数窗口。
3. 正常发送消息。助手消息显示可折叠的工具过程、查询／网址、结果及来源链接，正文与可见思考继续流式 Markdown 渲染。关闭页面后任务继续；第二设备读取已保存结果。

会话选择自动保存并随离线待发送固定，复制和备份保留选择及已保存过程，不重新执行模型或工具。新对话添加附件提前创建云端对话时，先校验并保存参数；无效参数不创建空对话。下一次新对话的工具恢复关闭，其他新对话参数继续保留。

发送前检查模型能力和服务是否已配置，失败保留输入和原选择；在线时重新读取不含密钥的服务状态，离线时使用已缓存的存在状态。客户端从会话选择构造显式的请求 `tools`；服务端仍独立校验，不根据消息历史或保存的偏好自动执行工具。摘要请求不启用联网工具。

密钥默认以空密码框及「已配置」状态展示，可输入替换、显式查看或清除。查看前先保存当前编辑，切换 Tab、关闭设置或退出后隐藏并取消未完成读取。输入及查看的密钥只保留在设置组件内存；公共查询和本机缓存只保存存在状态、每日上限和用量，不保存密钥。迟到的读取／自动保存响应不能在退出后恢复密钥或本机服务配置。

设置 Tab 在窄屏内横向滚动，关闭按钮固定在内容滚动区外。界面沿用 DaisyUI 的主题、输入和开关组件。

## 配置接口

以下接口均位于 `/api` 下，需要登录，响应使用 `Cache-Control: no-store`。写入还要求同源 Origin。

| 接口                          | 行为                                                                |
| ----------------------------- | ------------------------------------------------------------------- |
| `GET /settings/web-tools`     | 返回 `provider`、`hasApiKey`、`dailyLimit` 和 `usedToday`，不含密钥 |
| `GET /settings/web-tools/key` | 显式读取已配置的密钥                                                |
| `PUT /settings/web-tools`     | 保存服务密钥和每日请求上限，返回不含密钥的设置                      |

写入示例，密钥仅为占位符：

```json
{
  "provider": "tavily",
  "apiKey": "tvly-YOUR_API_KEY",
  "dailyLimit": 20
}
```

省略 `apiKey` 保留原值，空字符串清除密钥。密钥去除首尾空白后最多 4,096 个可打印 ASCII 字符，不接受内部空格或控制字符。每日上限默认为 20，允许 1–1,000 的整数；配置请求最多 8 KiB。供应商固定为 Tavily，不接受自定义端点或额外字段。

发送消息时，只有请求明确带有非空 `tools` 才加载服务配置；例如 `tools: ["web_search", "read_webpage"]`。普通聊天不启用工具，也不加载搜索密钥。未知或别名推断能力允许主动尝试；明确不支持、未配置服务或已知每日额度耗尽均在写入消息和调用模型前拒绝。

服务设置独立保存在 Library。接受任务时固定密钥和每日上限，后续修改密钥不改变在途任务；清除密钥阻止新任务，已接受任务沿用原配置。降低全局每日上限会在每次外部请求前立即生效；提高上限不能超过该任务接受时固定的上限。

## 请求与结果边界

请求只发送到固定的 `https://api.tavily.com/search` 或 `https://api.tavily.com/extract`，使用 POST JSON 和 Bearer 鉴权。搜索固定为 general／basic，最多五条结果，关闭自动参数、生成答案、原始正文、图片和图标；读取一次只提交一个公开 HTTPS URL，使用 basic、纯文本及 10 秒服务端提取期限。接口依据：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Tavily Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。

| 边界           | 实现                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 单次工具期限   | 15 秒取消期限，受根任务剩余期限约束；额度 RPC 返回后复验取消状态，再决定是否开始 HTTP 请求 |
| 原始 JSON 响应 | 最多 512 KiB，同时检查声明长度和实际读取字节                                               |
| 编码及格式     | JSON Content-Type、严格 UTF-8，拒绝损坏及异常结构                                          |
| 返回来源       | 最多五个，正文总计 12,000 个 UTF-16 码元                                                   |
| 裁剪           | 添加截取标记，不切断代理对，移除不允许的控制字符                                           |
| 单次持久化结果 | 最多 64 KiB，重新验证调用身份和来源对应关系                                                |
| 整个任务       | 最多四次模型、六次工具认领，十分钟及既有上下文预算                                         |

读取接口即使返回 HTTP 200，也必须具有一个成功结果且没有 `failed_results`；没有正文明确失败。搜索无结果可以返回空来源列表。

请求使用 `redirect: 'manual'`，所有非成功状态均拒绝，不跟随重定向；同时检查响应最终 URL。真实本地 workerd 验证发现该运行时不支持 `redirect: 'error'`，因此不能以 Node 中可构造 Request 的单元测试替代原生验证。密钥只随固定服务请求发送，不发送到待阅读网页；DO 不直接抓取任意模型返回的 URL。

输入 URL 和来源链接共用公开 HTTPS 语法校验：拒绝凭据、IP 字面量、localhost、常见内部后缀、非标准端口及控制字符。**语法校验不能证明 DNS 解析目标公开**，实际网页抓取由 Tavily 完成，第三方的 DNS、重定向及网络隔离未在此检查点证明。

## 每日额度与停止

Library 的 SQLite 事务维护全局 UTC 每日尝试计数。对话、任务和调用 ID 的组合先计算 SHA-256 标识，再在外部请求前原子认领并同步存储；不同对话并发不能超过较小的“任务已接受上限／当前全局上限”。失败、取消和结果未知的尝试仍占用额度，同一已认领调用不会再次计数。账本保留当天和前一天，在后续认领时删除更早记录，无需周期性 Alarm。

已知耗尽时，新任务返回 429，不写入消息或调用模型；已接受任务在下一次认领时耗尽则结束整个任务，不继续工具或模型。上游 401／403、429／432／433 和服务请求超时也结束整个任务。其他可持久化的工具错误可以交给剩余有限模型轮次处理；所有服务请求均不自动重试。DO 重置后，已认领但结果未知的工具保存中断错误，仅未认领步骤可继续。

这是请求尝试次数上限，**不是供应商 credits 或金额预算**；也不承诺免费账单。模型请求仍可能收费，失败请求是否计费由服务商决定。

工具 RPC 因鉴权、额度或服务期限停止根任务后重新安排 Alarm，使终态通知及时清理；不会等待旧根任务期限。原生 HTTP 401／429 回归检查 Workflow 完成后待通知归零，不通过测试入口人工触发清理。

## 密钥与数据

服务设置默认接口不返回密钥，只有专门的鉴权读取接口可以显式查看。响应错误不会带回上游原始错误体，来源结果若包含配置密钥则拒绝保存。

持久化的密钥只存在 Library 和已接受任务的私有运行配置；网页输入或显式查看期间可存在当前设置组件内存。不进入 Workflow 参数、公共消息、WebSocket 帧、本机持久缓存、导出或备份。任务终态清理私有运行配置。复制及恢复保留已保存的公开工具过程，不重新执行。恢复备份不覆盖当前服务设置，新的安装需要重新配置服务密钥和额度。

## 验证

281 项单元测试、应用／Worker／工具类型检查、测试与 fixture 的独立严格 TypeScript 检查、生产构建及差异检查通过。完整浏览器套件首次运行 245 项，244 项通过，一项跨对话搜索在 Markdown 重绘时立即读取高亮而失败；改为等待目标文字实际高亮后，4 项搜索回归通过。12 项联网网页场景分批全部通过，包含新增的无效参数附件校验；当前主套件共 246 项场景已分批验证。最新生产构建的两项 PWA 回归通过，桌面和 390px 窄屏设置页已检查。

覆盖四协议经过生产适配器的搜索及读取、无在线客户端、固定密钥、全局并发额度、Library／Conversation 重置、停止、真实 15 秒超时、降低上限、鉴权／额度错误、响应体边界、重定向拒绝、显式密钥读取和公共备份隔离。网页场景另覆盖自动保存、独立开关、未配置／未知能力的草稿保留、离线重发、跨设备、附件创建、复制／恢复及退出后的迟到响应。

所有外部响应均由隔离 fixture 模拟，没有部署、创建远程资源或进行真实付费调用；不证明实际搜索质量、Tavily 账户权限或 Workers Free CPU／SQL 消耗。工具路径增加服务端解析、私有日志及 SDK 回放，不能沿用普通聊天的资源指标作免费层保证。整体范围继续按[路线图](../plans/serverless-feature-roadmap.md)逐项核对。

后续[工具资源基线](../measurements/tool-measurements.md)已记录七场景的模型／服务尝试、两类流日志、两个 DO 的 SQL 和 Workflow 步骤，要求私有数据、通知及 Alarm 清理完成；283 项单元测试和 30 项工具／服务原生回归通过。该本地证据仍不代替真实平台 CPU、Workflow 引擎存储或免费账单。
