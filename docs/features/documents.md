# 文本文件输入

聊天框可发送 UTF-8 文本、Markdown、代码、CSV、HTML／XHTML、SVG／XML、JSON／JSONL、YAML、TOML，以及未知扩展名和无扩展名的文本文件。扩展名和 MIME 只选择处理路径；是否为文本由完整 UTF-8 与控制字符验证决定。PNG／JPEG／WebP 和 PDF 继续使用专门路径。可以只发送文件，也可以与文字、图片一起发送。

## 准备与预览

保留 BOM、换行和原始内容；HTML／SVG 始终作为转义纯文本展示，不执行脚本或加载内嵌资源。空白文件、非法 UTF-8 和包含二进制控制字符的文件会明确报错。CSV 的可选行列信息由 Papa Parse 提供，语法不规范但有效的文本仍可按原文使用。

原文件单次上传上限为 100,000,000 字节；没有按文件数或累计容量设置的应用配额。超过 1 MiB 的普通文本增量验证并建立稀疏索引，不整包解码。预览每页最多约 8 KiB，前后翻页只读取相应范围。旧的 32 MiB 全文读取工作集保护仍用于显式整包读取，不限制范围预览和按需工具。PDF 仍由浏览器提取，支持选择页码或片段。

预览和下载要求登录并检查对话权限，响应不进入 Service Worker 缓存。下载使用纯文本和禁止内容嗅探的响应头。弹窗关闭按钮固定可见，关闭不会提交聊天。

## 选择输入方式

在聊天草稿的文件预览顶部选择：

- **自动**：小文件全文输入；超过约 8,192 个估算 Token 或不适合剩余预算时，支持工具的模型使用按需读取。
- **全文**：将全文或所选 PDF 范围直接放入上下文，仍需满足模型窗口及单次请求工作集。
- **按需**：先向模型提交文件清单，再由模型定位并读取片段。已知不支持工具的模型不能使用此方式。

按需工具与网页搜索开关、联网服务密钥无关。模型可调用 `attachment_info` 查看规模、`attachment_search` 搜索字面关键词、`attachment_read` 按 UTF-8 字节范围、行、PDF 页或等距位置读取。搜索支持多关键词、重叠命中、计数、位置和片段；长搜索通过检查点继续，内部批次不要求模型反复请求。

文件清单只表示可读，不表示模型已经看过全文。工具过程显示实际读取范围和扫描进展；输入回执区分清单、工具返回片段和后续模型步骤的提交。分页未结束与扫描未完成分别标记。抽样或搜索命中不等于通读。

## 保存与生命周期

原文件、规范文本和小型索引存于私有 R2；Library 保存元数据和索引引用。大文本复用通过完整验证的不可覆盖原始对象，不再复制全文。消息、草稿和任务只保存固定版本引用、选区和输入方式。内容哈希用于版本识别和备份校验，范围读取不会重新哈希全文。

历史、分支、重新生成、回答继续及历史摘要使用相同输入方式与预算。摘要不偷偷加载按需附件全文。后续提问不会自动携带之前的全部工具结果，模型可按当前清单重新读取。任务由服务端继续执行，不依赖浏览器在线。

复制与 ZIP 备份／恢复保留规范文本和输入方式，并为恢复的对象建立索引。删除先检查消息和活动任务引用，再回收原文与索引。公开分享不因此暴露附件原文、清单或私有读取接口。

已有部署升级须先执行[离线迁移](../operations/offline-storage-migration.md)。历史索引缺失时明确要求维护，不在普通请求中自动下载全文重建。
