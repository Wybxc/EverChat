# 使用指南

[项目首页](../README.md) · [文档索引](README.md)

## 首次配置

登录部署者提供的网站后，打开「设置 → 供应商」，添加供应商并填写非空名称、API 类型、基础地址和密钥。密钥由供应商提供，EverChat 不提供模型额度。

| API 类型                                 | 常用基础地址                                       |
| ---------------------------------------- | -------------------------------------------------- |
| OpenAI Chat Completions                  | `https://api.openai.com/v1`                        |
| OpenAI Responses                         | `https://api.openai.com/v1`                        |
| Anthropic Messages                       | `https://api.anthropic.com/v1`                     |
| Gemini                                   | `https://generativelanguage.googleapis.com/v1beta` |
| DeepSeek（选择 OpenAI Chat Completions） | `https://api.deepseek.com`                         |

基础地址使用 HTTPS，保留供应商要求的版本路径，不要附加具体生成接口路径、查询参数或账号信息。兼容供应商请填写其提供的基础地址。

获取模型列表或手动添加模型后，勾选需要启用的模型。模型 ID 用于实际请求，显示名可自行修改；获取到的新模型默认禁用，手动添加的模型默认启用。重新获取列表会保留已有模型的显示名和启用状态。修改 API 类型或端点不会清空其他输入。

设置修改会自动保存，通过浮动提示显示进度；成功提示自动消失，失败时保留当前编辑，可在提示中点击重试。密钥默认遮蔽，可显式查看；切换设置分类或关闭窗口后隐藏。删除供应商会删除对应密钥和模型列表，已保存的对话仍保留。

## 选择模型与预设

在聊天框选择模型；名称旁同时显示供应商，便于区分同名模型。「设置 → 对话」可设置默认模型和自动标题模型；自动标题默认关闭，启用或手动生成标题会额外调用模型。

聊天框选择按对话保存在本机，切换、刷新和前进／后退后恢复。没有本机选择时，尝试从该对话最近的普通模型回答恢复；停用或删除模型后回退到可用默认模型。新对话沿用最近手动选择。

在「设置 → 预设」维护系统提示词和默认预设。新对话顶栏可快速切换预设，会话参数也能应用预设或编写自定义提示词。应用预设后，后续修改或删除预设不会改变该对话已经应用的内容。模型可以使用默认提示词，也可以配置专属提示词。

支持的模型可在聊天框选择思维强度。供应商实际返回的思考内容始终保留，以 Markdown 流式显示，并可折叠；模型未返回思考时不会凭空生成。生成信息显示 Token、耗时、正文和思考字数；未报告的用量不会补成零。

## 对话与版本

侧栏列出对话、置顶项及生成状态，每个对话有独立链接。可从菜单重命名、置顶、复制链接、复制对话或删除。新对话在首次发送或上传文件时保存，各对话草稿独立保留。移动端通过按钮打开和关闭侧栏。

空输入框按 `↑` 调出当前分支最近发送的提问，再按 `↑`／`↓` 切换历史文本；向下越过最新一条回到空输入框。输入或修改任何文字后，方向键只移动光标，清空输入框才重新启用历史切换。此操作不修改已保存的消息，也不重复附加历史文件。

提问和回答下方均有编辑入口，在原位置修改文字。`Enter` 换行，`Mod+Enter` 保存，`Escape` 取消；底部未发送草稿和附件独立保留。

- **编辑提问**：保留旧版本，使用当前所选模型生成新回答。
- **重新生成**：使用点击时聊天框选中的模型、思维强度和联网选择，创建新的回答版本。
- **继续生成**：中断或达到输出长度的回答下方可直接继续；其他回答在更多菜单中继续。新输出接在原文末尾，保存为兄弟版本，原回答和旧后续保留。使用当前聊天框所选模型及参数，不会发送或清空未发送草稿。
- **编辑回答**：保存为标有「手动编辑」的新版本，不调用模型。
- **切换版本**：通过气泡下的箭头选择分支。旧版本及其后续消息留在原分支，后续提问只沿当前显示的分支继续。
- **从这里继续**：从选定回答另起后续提问，保留其他路径。

生成中请先停止或等待完成，再编辑、删除或继续。供应商断流时，已可靠保存且包含正文的部分回答会作为正式版本保留，显示中断提示，后续提问可以带上这段正文。继续生成会重新发送原问题、已有回答和字面指令「继续」；普通后续提问只携带拼接后的那一条回答。生成信息可查看每次请求的模型、用量及结束情况；思考和工具过程按阶段分开。续写可能重复或改变文风，可用编辑回答整理。

复制整段对话会保留所有已保存分支与文件，并创建独立副本；消息菜单中的「复制到新对话」仅复制从开头到该消息的路径，不含旁支及后续。删除源对话不影响副本。

删除消息后，后续上下文跳过被删除的版本；其文字若已被另一个续写版本继承，仍属于该续写版本，删除来源不会截掉它的前缀。删除提问后，其回答也不进入后续上下文。删除整个对话会停止生成并清理对应记录，操作需要确认。

## 上下文与联网

「会话参数」按常规、上下文和工具分类。可调整提示词、Temperature、Top P、输出预算、历史范围和摘要；模型不支持的采样项保持禁用。参数自动保存，新任务使用发送时的配置，后续修改不影响已经接受的任务。

输出预算在上下文分类中配置，默认不设置请求输出上限。输入框的上下文入口提供 Token 近似估算和将省略的历史条数；这些估算用于规划，不是精确计费。超过预算时保留草稿，不静默裁剪单条消息。

通过对话菜单的「压缩历史」生成摘要，或在会话参数中启用自动压缩。覆盖边界下方会显示分割线和摘要消息；后续回答始终使用当前分支的有效摘要及之后的新消息。原始消息仍可回看；摘要会额外调用模型，也可能遗漏信息，可重新生成或删除。详见[上下文预算](features/context-budget.md)和[历史摘要](features/history-summaries.md)。

在「设置 → 联网」选择 Tavily 或 DeepSeek，配置服务密钥和每日请求上限。聊天框的「联网搜索」按钮同时开关搜索和网页读取，每个新对话默认关闭。模型决定是否实际调用工具；开启后重新生成也可以联网，过程和来源按执行顺序显示在思考区。每日上限按请求尝试次数计算，不等同于费用上限。

## 文件与阅读

聊天框支持选择、粘贴图片，以及拖入图片／文件；对话文件菜单可管理已保存文件。支持 PNG、JPEG、WebP、UTF-8 文本（包括 HTML、SVG、代码、Markdown、CSV 等）和含文字的 PDF，图片问答需要支持图片的模型。

单个原文件最多 100,000,000 字节，不设文件数量及累计容量配额。在草稿文件预览中可选择自动、全文或按需输入；长文本可由模型搜索和分段读取。PDF 在浏览器完整提取文字，再按模型容量选择页码或片段；不支持扫描图片的 OCR 或加密 PDF。详细规则见[对话文件](features/attachments.md)、[文本输入](features/documents.md)和[PDF](features/pdf.md)。

正文与思考支持 Markdown、保留软换行、代码高亮、Mermaid 和数学公式。公式可用 `$…$`／`\(…\)` 或块级 `$$…$$`／`\[…\]`。长用户消息可展开或折叠；长代码、表格和公式在自身区域横向滚动。

对话导航提供顶部、底部、上一条回答和下一条回答。按钮在滚动、靠近导航区域或触屏轻点消息区时显示，停止交互后隐藏。查阅旧内容时暂停跟随生成，跳到底部恢复跟随；系统设置「减少动态效果」时跳过滚动动画。

## 搜索与快捷键

全局搜索查找对话标题、正文和思考，结果高亮关键词；打开结果可恢复对应分支。离线时可查本机已读取的标题和当前对话，跨对话正文搜索需要联网。当前对话搜索支持匹配间跳转，命中折叠思考时会展开。

`Mod` 在 macOS 为 `⌘`，其他平台为 `Ctrl`。右上角菜单可查看快捷键。

| 快捷键        | 操作                     |
| ------------- | ------------------------ |
| `Mod+J`       | 新建对话并聚焦输入框     |
| `Mod+K`       | 全局搜索                 |
| `Mod+F`       | 搜索当前对话             |
| `Mod+Shift+L` | 聚焦输入框               |
| `Mod+B`       | 在非文本编辑区域切换侧栏 |
| `Escape`      | 关闭搜索或取消消息编辑   |

## 分享、备份与用量

从对话菜单「分享当前分支」预览并创建只读链接。分享是固定快照，包含正文、思考和模型名称，不含供应商名称及附件原文；思考默认折叠。后续编辑原对话不会更新已发布快照。

拥有完整链接的人无需登录即可阅读。可选择有效期或永久有效；到期后链接失效并自动清理存储，也可在「设置 → 分享」删除。删除无法收回接收者已经保存的内容。

文件菜单支持 Markdown、纯文本、HTML 导出，以及 `.everchat.zip` 备份与导入。备份保留消息关系、思考、模型信息、相关设置、预设及已保存文件，不包含 API 密钥或正在生成的未保存尾部；恢复后生成独立对话。详见[附件备份](features/attachment-backups.md)。

「设置 → 用量统计」按供应商、模型、请求和趋势汇总只读统计。模型价格默认取自 models.dev 快照，可在价格配置中覆盖；历史请求保留当次价格。未知价格不会视为免费，费用估算不代替供应商账单。

## PWA、离线与通知

可将网站安装为独立应用。在「设置 → 通用」检查更新、更新应用或修复离线资源；更新可能需要等待下载，未保存设置或上传等操作完成后才能安全重载。

已下载的应用和已读取对话可离线打开，新消息保留为待发送，恢复网络后提交。首次访问、登录、上传和首次加载可选渲染模块需要联网。关闭页面前，确认消息已被云端接受；本机尚未发送的消息需要恢复网络后才能开始生成。

「回答通知」可选始终发送、不发送、仅在无焦点或后台时发送。后一选项在同一账号任一设备的页面可见且有焦点时抑制提醒。每个浏览器或 PWA 都需单独启用并授予系统权限；iPhone／iPad 请先添加到主屏幕。

「页面通知可用」仅表示页面在线时可通知；「后台推送已就绪」才表示已建立后台推送订阅。通知仍受系统权限、专注模式和网络影响；点击通知可打开对应回答。

共享设备使用后请「退出并清除本地记录」。离线阅读数据保存在当前浏览器，不能代替备份；退出还会进入 Cloudflare Access 退出流程，可能影响同一账号的其他 Access 应用。

## 遇到问题

- **设置保存失败**：保留编辑内容，恢复连接后重试，确认显示「已保存」。
- **供应商报错**：展开「错误详情」，查看阶段、HTTP 状态、模型和请求 ID，核对协议、端点、密钥与供应商额度；复制诊断前仍应检查私人信息。
- **显示“保存中”或连接中断**：等待同步确认；提交结果未知时使用原请求重试，不必反复新建消息。
- **Markdown 模块加载失败**：原文仍可阅读，联网后用消息下方入口重新加载，草稿会保留。
- **达到容量限制**：先导出备份，再按提示整理附件、复制所需分支到新对话继续，或联系部署者排查；具体资源边界见[免费层资源政策](architecture/free-tier-resource-policy.md)。
