# 思考展示与离线迁移执行记录

日期：2026-10-18。

## 已实现

- 新工具任务保存每轮工具边界在累计公开思考中的 UTF-16 位置，和该轮文字、工具登记在同一事务提交；状态更新沿用原位置。元数据存入原有 JSON 列，最多每工具轮次一条，不增加逐 Token 日志、SQL 表或后台调度。
- 单个「思考过程」按思考 → 搜索 → 后续思考 → 读取网页 → 思考展示，正文独立。每轮思考使用共享 Markdown 渲染，已完成片段静态、当前片段流式；工具状态和来源展开保持原调用标识。
- 搜索把所有片段作为一个逻辑思考字段，跨片段高亮使用多个 Range，忽略中间工具卡。错误摘要在思考折叠后仍可见，定位时打开所有祖先折叠区并聚焦调用。
- 同步和备份验证位置范围、轮次、单调性及 Unicode 代理对；无效状态请求权威快照恢复。复制和恢复保留位置，不重做模型或联网请求。旧记录缺少位置时统一放在同一思考区末尾，不扫描改写历史数据。
- 删除 Library 启动时历史索引回填及新建空对话的无效扫描。`pnpm ops:storage convert --rebuild-search` 从完整本地备份重建索引，准备维护窗口补丁；缺失清单或内容损坏时回滚。普通消息增量索引与主动复制／导入后的索引仍是业务流程。

## 验证

386 项单元测试、原生 workerd 运维测试、类型检查和生产构建通过。离线 CLI 验证无远程请求、断点重试选项锁定；本地索引及维护导入验证 FTS 完整性，回滚从备份字段恢复虚表，无需搬运影子表。

Chromium 已验证四种模型协议的三段思考／两轮工具穿插、来源展开状态、刷新、跨段搜索及工具文字排除；公式、软换行、流式思考及回答渲染回归通过。原生 Workflow 回归覆盖后台完成、重启中断、取消／超时、预算、换设备、复制及备份恢复；私有续接在终态清理且不进入公开快照。保存桌面浅色及移动深色合成截图检查，无水平溢出。

Library 重启／读取回归确认不创建历史迁移任务。生产只读检查搜索返回 200、`indexing: false`，现有历史索引已就绪；本次不改变 SQL 格式、不停机迁移生产数据。既有库版本门禁继续拒绝未完成离线迁移的旧格式。

WebKit 四种协议的顺序展示、跨段搜索、DeepSeek Responses 思考恢复和折叠区搜索均通过。长回答滚动测试在流式结束时失败：主视口回到顶部，距底部 2,422 px；使用改造前的 MessageView 和 ToolActivity 完整对照仍在同一断言失败，属于既有滚动问题，未记为通过，也未在本次迁移改动中修复。

离线迁移改造 `3421138` 已推送，Workers Builds 成功。思考展示改造继续采用 `main` 的 Workers Builds；推送成功不等同于部署完成，发布后核对构建与生产只读接口。
