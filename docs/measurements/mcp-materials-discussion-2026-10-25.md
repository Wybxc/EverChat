# MCP 文件版本与讨论上下文验证

日期：2026-10-25。实现分支 `codex/mcp-discussion-improvements`，PR #10。此记录暂只包含本地结果，尚未完成生产离线升级或平台资源验收。

## 行为与证据

- 新增批量 prepare／小文件 put／有界 get／保护性 delete 四工具，与既有 R2 接收、文档解析、引用、快照、清理共用一套存储。批次按文件分行，不保存签名 URL 或 base64。HTTP 私有下载校验 Bearer Key，不以 cookie 或 ref 代替授权。
- `.typ` 作为文本；客户端辅助程序使用官方 MCP client，读取实际字节、计算摘要、客户端 PDF.js 提取、批量 PUT，禁止重定向和向 R2 附带 Key。显式状态文件固定上传身份，响应丢失可以使用原批次重试。
- `documentRef` 关联逻辑资料、`versionRef` 标识不可变版本。精确分支上的材料绑定独立于最近消息后缀与摘要预算。替换排除旧材料块，保留原消息、旧回执、兄弟分支；同请求多个 replace 产生歧义时拒绝。失效摘要停止注入，换版不会自动花费一次重新压缩。旧回答里引用的旧结论不被自动改写。
- 文件排除清单包含附件、逻辑文件与版本身份及原文／文本哈希，不误算整条消息省略数；显式复制／ZIP 恢复保留来源版本身份并重映射物理附件。
- `discussion.independent`／`review` 新建普通对话，只读白名单用户背景、已解析文件和明确目标回答。校验消息 revision／全文 SHA-256、可选 UTF-16 范围与引文哈希；不继承父链、思考、工具结果或摘要。一次性可见背景文本复用普通消息／回执／备份，不新增讨论数据库。它不能证明模型结论正确或资料语义独立。

## 已通过

- 537 项全量单测、类型检查、生产构建和离线运维集成。
- 五组新的 MCP 本地 DO/R2 集成：四协议实际 Typst 附件与输入回执；换版／并列／同分支后续固定材料／兄弟分支隔离；直接 PUT 后自动接收及未上传同 requestId 恢复；17 文件分页／PDF 原文与派生流／第二页选择／辅助程序幂等；独立提案与审查／篡改引用／跨 Key 拒绝。
- 换版组合场景起初超过 60 秒的单测试限时；追踪显示已完成断言均通过，测试包含四协议的连续生成，每次轮询约 3 秒。改为该组合场景使用 Playwright slow 时限后通过，未修改业务等待或加入应用超时豁免。
- 全量单测首次遇到两个帮助断言：旧测试仍把新附件工具名视作非法帮助参数。更新为真正不存在的工具名后，全量通过。
- 本地沙箱不能绑定回环端口，网络相关单测与运维测试在获准的本地运行环境完成，不把 EPERM 解释成应用失败。

完整 MCP／网页文档／PDF 回归 43 项通过，长版本说明导致字节分页的辅助程序补测通过。生产 schema 4 须在维护窗口中备份、在本机转换、写回及逐项核验；不在在线请求中转换。平台 CPU、内存与新增 SQL/R2 用量仍需单列实测，本地通过不构成 Workers Free 的 10ms CPU 保证。批次页和文本页有界，读取不会触发模型、全文导出、周期 SQL 心跳或历史回填。
