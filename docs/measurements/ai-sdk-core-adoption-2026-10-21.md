# AI SDK Core／UI 集成：阶段 0–2 本地记录

日期：2026-10-21。对应[深度集成计划](../plans/ai-sdk-core-ui-adoption-plan.md)。状态：Core 与工具容错已接入，本地验证通过；前端 UI 状态迁移、离线维护切换和平台资源验收尚未完成，未部署。

## 调用边界

安装并精确锁定 `ai@7.0.145`、`@ai-sdk/react@4.0.149`；后者依赖同版本 Core。现有 Provider V4 适配器继续负责四种原生协议。普通回答、摘要与工具模型轮次经统一 Core 流入口；标题与能力探测改用 `generateText`。不提供自动执行的工具 `execute`，不启用 Core 多步循环、请求重试或流内重试。

流入口使用公开的 `experimental_streamTextLowMemory`，它与 `streamText` 共用引擎，只有一个消费者，不保留可供再次读取的完整流。该版本在声明 tools／toolChoice 时仍收集本轮内容，不能宣称工具场景完全没有 Core 聚合开销。没有使用 `_internal` 配置、SDK 内部导入或另一个原始响应 tee；升级此实验 API 必须重做资源与协议验证。

公开 `wrapLanguageModel` 中间件观察同一条原生流。私有 collector 保留原生调用身份、完整结束证明和协议续接资料：Anthropic 分片签名拼接、redacted 内容、Responses 加密资料及全文／摘要处理、Gemini thought signature。Core 负责参数 JSON 与 Schema 解析；DO 保存候选与结果后由 Workflow 推进下一轮。

标题删除了旧 ProviderStream 的字节解码消费，继续保留请求前记账、独立预算、版本竞争和不确定执行后禁止自动重发。辅助响应读取共享有界读取器；标题 256 KiB、探测 64 KiB，均支持取消。探测要求工具而模型只返回文字时，Core 的 `ToolChoiceViolationError` 归为能力不匹配，计费用量仍通过调用结束回调保存。

非官方 Responses 的 `store:false` 请求补充由单一 helper 供流、标题和探测复用。关闭 SDK 全局原始 warning 日志；普通生成仍保留 EverChat 有界、脱敏的公共诊断。

## 工具行为

- 公开网页／引用目标允许 HTTP、HTTPS 与 8192 字符 URL；带密钥的联网服务端点继续固定 HTTPS，禁止自动跟随重定向。保留凭据、本地／内网、非网页协议、自定义端口等目标策略。
- 搜索逐条处理来源，缺少标题时使用域名，无效条目单独过滤，保留有效条目和有界警告。真实空结果可以成功，非空但全部不可用明确失败；根结构损坏、超限和凭据泄漏仍失败。
- DeepSeek 查询在 Core 校验与执行边界均按 128 个 Unicode 字符限制。模型 JSON Schema 与含自定义 Unicode 校验的运行时 Valibot Schema 分开配置；不能把不可转换的 `v.check` 直接交给 JSON Schema 转换。
- 无效 JSON／参数、未知工具在身份明确且原生流完整时形成不可执行候选，保存对应失败结果。合法兄弟调用继续，失败调用不会发出网络请求或占用服务额度。SDK 不伪造被原生身份检查拒绝的调用。
- 单工具 15 秒期限是局部失败；调用者取消、全局期限和存储失败仍停止任务。认证／余额／服务额度失败禁止后续服务请求，模型可以根据已有资料收尾。连续同一失败指纹且没有有效来源进展时关闭工具，没有新增固定轮数上限。
- 仍保留 SSE／异常 EOF、重复／缺失调用身份、finish 后内容、私有资料缺失等完整性边界；不会以“容错”修补截断参数或执行不完整调用。
