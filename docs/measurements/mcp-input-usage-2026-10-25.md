# MCP 输入回执与用量依据阶段验证

日期：2026-10-25。分支：`codex/mcp-discussion-improvements`；草稿 PR #10。尚未迁移生产或发布，不代表完整讨论优化目标完成。

## 已接入

- 最终供应商请求边界保存输入来源／哈希、生效参数、工具定义指纹和最终适配请求指纹。先写组装依据，记账准入完成后再标记尝试发送；持久化失败时不发送付费请求。
- `everchat_run_context_get` 提供 manifest、排除清单及按需逻辑文本分页。消息和摘要引用已有不可变内容，应用生成文字一次固化；系统提示词全文不保存、不导出。工具后续步骤只保存新增公开投影并引用前一步，不保留 HTTP 正文、base64、私有推理续接或流事件历史。
- 回执进入普通对话备份／恢复；恢复重映射消息和步骤引用，并保留 `originStepId`。删除回答同时删除所属回执；被引用来源删除时返回内容不可用。旧请求不回填。回执不另存系统提示词全文；活跃任务的既有配置存储规则保持原样。
- 原生 Token 字段来源穿过公开语义事件、持久检查点、生成结果与用量账本。缺失值为 null，真实零保留，派生值明确标记。多步骤按字段记录覆盖数，缺一步则只给已知小计，完整总量为 null；任务结束独立于用量完整性。
- 修复 Gemini 只返回 `promptTokenCount` 时未识别用量更新的问题；只有 total、SDK 规范化补零以及零计数与非零 total 冲突均有测试。
- `everchat_run_usage_get` 按需分页读取既有模型步骤账本，返回价格来源／生效时间／快照 ID 和定点费用的十进制字符串；不重算历史、不查询全账户、无额外模型调用。每次状态轮询不查询 Usage DO。

## 验证范围

- 四协议模拟供应商在唯一一次 fetch 中核对已经保存的请求指纹和实际适配正文一致，内部来源字段未发送给供应商，回执不包含供应商凭据或系统提示词全文。
- SQLite 单测覆盖组装与尝试发送分离、重复请求围栏、来源／摘要包装、Unicode 分页、内容删除、增量工具步骤、只读查询不写库，以及备份恢复后的来源映射。
- 最新完整单测 526 项通过；类型检查和构建通过。新增输入清单／文本、逐字段覆盖、费用读取、跨 Key 拒绝断言后的 MCP 四协议、现代／legacy 客户端和生命周期集成 3 项通过；离线运维集成 1 项通过。
- 联网工具多步骤超时场景单独复测通过（40.1 秒）。此前与代码修改同时运行的一次测试返回通用失败而缺少 TIMEOUT 标记；运行期间存在开发服务重载，独立复测不再发生，尚不能将一次通过视为已确定该次失败的唯一原因。本次未改动超时逻辑。
