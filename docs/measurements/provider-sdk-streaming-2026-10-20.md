# SDK 流解析、透明摘要与输入历史执行记录

日期：2026-10-20。对应[实施计划](../plans/provider-sdk-streaming-plan.md)。

## 已实现

- 供应商真实响应由匹配协议的 AI SDK `doStream()` 解析一次。官方 OpenAI Responses 和第三方兼容 Responses 分别使用对应适配器；浏览器仅解析 `events-v1` 应用事件。
- 正文、思考、用量和结束状态统一转换；Responses 完整思考优先于摘要，避免重复追加。HTTP 正文、流内错误、异常 EOF、内容过滤和原始结束原因保留脱敏诊断，错误不能被后续 `stop` 覆盖。
- 工具轮次在同一次消费中校验并收集私有结构化续接，移除原始字节日志与结束后的重复解析。签名、加密状态和原始工具事件不发往客户端；终态清理私有续接和请求配置。
- 多端预览、恢复和低频检查点继续工作。部分回答保留为历史上下文，不自动重试供应商。单个流事件、正文与思考合计、私有续接等容量保护继续生效。
- 移除「使用历史摘要」开关。摘要在覆盖边界后以分割线和直接展开的消息呈现，有效摘要始终用于匹配分支；失败、未完成、空白或截断摘要不替换原文。
- 空输入框可用上下键调出当前分支的用户提问；未经编辑可连续切换。任何修改都会锁定历史切换，即使撤销回原文；清空才恢复。输入法和普通编辑不受影响。

## 验证

- `pnpm typecheck`、`pnpm build`、`pnpm format:check` 和 `git diff --check` 通过。
- `pnpm test --test-timeout=15000`：462 项通过。
- `pnpm test:operations`：原生离线备份／补丁重放场景通过。旧私有流表和退休摘要设置字段只在本地运维转换中清理；旧协议任务仍运行时拒绝转换并回滚。
- 流式、摘要及生成／工具集成相关浏览器组首轮 70 项中 69 项通过。剩余一项在初始用量到达、正文尚未持久化时过早断言；改为等待权威快照中的部分正文后，四协议分片恢复用例全部通过。
- 输入历史、桌面发送、触屏换行及四协议恢复聚焦组 7 项通过，覆盖修改后撤销仍锁定、清空恢复、分支隔离和输入法。
- 供应商错误详情浏览器组 13 项通过，覆盖 HTTP／流内错误、断流正文保留并带入下一轮、复制／备份及脱敏。
- 普通流与工具流本地资源测量均通过。测量包装层保留流完成后才产生的私有续接属性，避免计数字节时改变工具执行行为。

浏览器验证使用本地 Cloudflare 运行时和模拟供应商；没有真实模型、搜索或网页调用。

## 本地资源测量

工作负载为 120 个片段、25 ms 间隔、每片基础文字 200 字符。普通流测量窗口为认领到终态；工具流另包含提交、Workflow、索引与清理，两者不能直接横向比较。

普通流原始报告：[provider-sdk-stream.json](provider-sdk-stream.json)。

| 场景           | 正文／思考增量 | 检查点 | SQL 写入行 | 数据库字节 |
| -------------- | -------------- | ------ | ---------- | ---------- |
| 在线正文       | 120／0         | 3      | 55         | 356,352    |
| 在线正文与思考 | 120／120       | 4      | 70         | 434,176    |
| 断线长正文     | 120／0         | 7      | 95         | 569,344    |

三种场景的同步事件载荷持久化均为 0；增量数明显高于检查点数，保持批量写入。

工具流原始报告：[provider-sdk-tools.json](provider-sdk-tools.json)。

| 场景                  | 模型／工具请求 | 检查点 | Conversation SQL 写入行 | 数据库字节 |
| --------------------- | -------------- | ------ | ----------------------- | ---------- |
| Chat Completions 在线 | 2／2           | 4      | 207                     | 327,680    |
| Responses 在线        | 2／2           | 4      | 206                     | 327,680    |
| Anthropic 在线        | 2／2           | 4      | 206                     | 327,680    |
| Gemini 在线           | 2／2           | 4      | 204                     | 327,680    |
| Chat Completions 断线 | 2／2           | 4      | 207                     | 327,680    |
| 联网服务拒绝          | 1／1           | 1      | 122                     | 303,104    |
| 多轮交换              | 6／10          | 8      | 579                     | 335,872    |

全部工具场景的私有原始流写入和同步事件载荷均为 0。终态时私有续接、固定上下文、待处理索引／通知和 Alarm 均清空，在线客户端状态与持久化快照一致。

工具报告版本 2 中沿用的 `upstream.modelBytes` 字段统计 **SDK 转换后的 `events-v1` 字节**，不是供应商 SSE 流量；`modelBytesSource` 明确标识该口径，不能与旧报告的原始供应商字节直接比较。报告的 SQL 游标计数及墙钟时间都不是 Cloudflare CPU、计费请求或活跃 GB-s；诊断轮询也使本次测量无法验证自然休眠。真实平台资源与账单仍需另行验收。

## 发布与存储边界

发布前只读检查旧版进行中任务；旧 `raw-sse-v1` 任务须完成或停止，不能交给新解码器。已完成消息沿用保存的正文、思考和生成信息。旧字段、表及历史数据没有在访问请求中改写，本轮未执行生产离线清理；需要整理时使用[本地运维流程](../operations/offline-storage-migration.md)。
