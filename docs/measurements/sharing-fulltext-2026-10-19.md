# 分享全文与简化管理验收

日期：2026-10-19。本地验收使用隔离数据库、模拟供应商和实际生产前端构建，不改动生产分享及对话。

## 变更

- 分享页沿用对话宽度，提问靠右，复用 `UserMessageBubble`；回答靠左，继续使用安全 Markdown、公式与代码渲染。
- 页面统一由浏览器文档滚动，取消固定 `100dvh` 内部滚动，并只对公开入口解除 `html/body/#root` 的固定高度。修改前，60 段长内容的文档高度仍为 720px、内部有一个纵向滚动容器；修改后文档与根容器随内容伸展，短内容至少填满一屏，顶部栏保持吸顶。
- 回答标题显示快照中的模型显示名，缺少显示名时使用模型 ID，不包含供应商名称或 ID。每条回答只在首块保存一次模型名；旧快照未保存模型名时显示 EverChat，需要重新创建才能补齐。
- 新分享始终包含供应商返回的思考内容，不再提供包含开关；访客看到的思考默认折叠，可手动展开。历史快照不会自动补齐未保存的思考。
- 公开 GET 一次返回全文，取消“继续阅读”和公开分页接口。SQL 游标逐块形成同一个 JSON Response，由 Worker 直接转发，避免服务端全量缓冲与重新编码；HEAD 只验证令牌。
- 创建时可选永久、1 小时、1 天、7 天、30 天或指定本地时间，默认永久；服务端验证未来时间，重复发布不改变原有效期。到期立即拒绝 GET、HEAD、重新复制和发布重试；DO Alarm 分批自动删除正文块、元数据和凭据，大快照每批最多 128 块，不增加轮询、Workflow 或按访问写入。已打开的公开页到期后清除显示，长有效期不会溢出浏览器 32 位计时器。
- 管理只保留复制和删除，并显示到期时间；主动删除前确认，成功后在同一事务中删除元数据、令牌及全部正文块。删除原对话同时清除分享与草稿，保留防止延迟任务重建的对话删除标记。
- 数据表结构不变，复用已有 `expiresAt` 和 Alarm，没有在线迁移或历史内容回填，也不延长已有链接的访问期限。

## 验证

- `pnpm test`：433 项通过，包含完整 JSON、块顺序、缺块拒绝、传输取消、永久／限时链接、到期边界、批量物理删除及模型名白名单回归。
- 本地浏览器创建／删除：桌面、390px 手机各通过；能指定到期时间，空值与过去时间不可发布，保存值与所选本地时间一致；取消确认不删除，确认后链接返回 404。
- 原生 Worker／DO 集成：2 项通过，包含固定分支、不泄露私有元数据、默认折叠思考、Markdown 安全与大快照全文重组。真实本地 DO Alarm 在限时链接到期后自动清除记录，无需访客触发写入；公开页同时清除已展示内容。开发 StrictMode 取消的初次 effect 不计入已完成传输。
- 实际构建 + 根 SW：Chromium、WebKit 共 6 项通过；一次页面加载仅一次公开数据请求，4 条消息及末尾正文同时可用，没有私有 API 请求。长内容使用一个文档滚动条、根高度与内容一致，短内容不产生多余滚动；手机深色无横向溢出。60 天有效期计时分段后按时清屏，不增加请求。更新协调与断网错误仍正常，API 正文不入缓存。

本次减少的是公开数据往返与重复鉴权，不减少全文本身的传输字节。浏览器收到完整响应后再显示内容；后台传输为一个 HTTP 响应内的分块，未增加长连接或周期写入。
