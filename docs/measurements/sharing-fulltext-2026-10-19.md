# 分享全文与简化管理验收

日期：2026-10-19。本地验收使用隔离数据库、模拟供应商和实际生产前端构建，不改动生产分享及对话。

## 变更

- 分享页沿用对话宽度，提问靠右，复用 `UserMessageBubble`；回答靠左，继续使用安全 Markdown、公式与代码渲染。
- 回答标题显示快照中的模型显示名，缺少显示名时使用模型 ID，不包含供应商名称或 ID。每条回答只在首块保存一次模型名；旧快照未保存模型名时显示 EverChat，需要重新创建才能补齐。
- 新分享始终包含供应商返回的思考内容，不再提供包含开关；访客看到的思考默认折叠，可手动展开。历史快照不会自动补齐未保存的思考。
- 公开 GET 一次返回全文，取消“继续阅读”和公开分页接口。SQL 游标逐块形成同一个 JSON Response，由 Worker 直接转发，避免服务端全量缓冲与重新编码；HEAD 只验证令牌。
- 创建不再设置到期时间，管理只保留复制和删除；删除前确认，成功后在同一事务中删除元数据、令牌及全部正文块。删除原对话同时清除分享与草稿，保留防止延迟任务重建的对话删除标记。
- 数据表结构不变，没有在线迁移或历史内容回填。旧失效／有有效期的记录继续按原规则拒绝，避免扩大已有链接的访问期限；新链接直到主动删除前持续有效。

## 验证

- `pnpm test`：430 项通过，包含完整 JSON、块顺序、缺块拒绝、传输取消、无到期新链接、物理删除及模型名白名单回归。
- 本地浏览器创建／删除：桌面、390px 手机各通过；没有思考开关、有效期、修改或独立撤销操作；取消确认不删除，确认后链接返回 404。
- 原生 Worker／DO 集成：2 项通过，包含固定分支、不泄露私有元数据、默认折叠思考、Markdown 安全与大快照全文重组。开发 StrictMode 取消的初次 effect 不计入已完成传输。
- 实际构建 + 根 SW：Chromium、WebKit 各通过；一次页面加载仅一次公开数据请求，4 条消息及末尾正文同时可用，没有私有 API 请求。折叠思考可展开，手机深色无横向溢出，更新协调与断网错误仍正常，API 正文不入缓存。

本次减少的是公开数据往返与重复鉴权，不减少全文本身的传输字节。浏览器收到完整响应后再显示内容；后台传输为一个 HTTP 响应内的分块，未增加长连接或周期写入。
