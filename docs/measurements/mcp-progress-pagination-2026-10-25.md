# MCP 进展与分页首批验证

日期：2026-10-25。分支：`codex/mcp-discussion-improvements`。未部署；这是[完整优化计划](../plans/mcp-discussion-observability-plan.md)中 A2／A3 的阶段证据，不代表七项反馈已经全部完成。

## 变更

- `everchat_run_get` 在运行中返回现有持久化正文和可选思考；每次页面提供尾部 `resumeCursor`、`contentFinal`、持久时间及 revision。
- 游标绑定请求、消息、通道、替换 epoch 和 UTF-16 偏移。移除固定累计偏移上限，仍保留单页 8,192 单元及代理对校验；越过持久边界明确失败。
- 供应商替换先前文本时令旧通道游标失效，返回 `OUTPUT_CHANGED`；单纯追加不会失效。
- 顶层六态保持，另给阶段、时间、正文／思考长度、摘要依赖、工具轮次和建议轮询间隔。只在实际阶段、工具状态或语义内容变化时更新紧凑记录；原始流的 keepalive、重复 checkpoint、状态查询均不更新进展。
- 完整性、长度截断与输出分页分离。长度结束不自动续写，不重复付费调用；断流／取消保留未知截断结论。
- 供应商请求序列化保护移到调用登记之前，避免本地请求体校验失败却被记为已开始外部调用。

## 本地证据

- TypeScript 检查通过。
- 全部单测 517 项通过，包含长输出超过原累计偏移限制、运行中尾部续读、跨 Key 拒绝、通道混用、版本变化、Unicode、stop／length／断流／取消及进展查询不写数据库。
- MCP 定向集成 3 项通过（46.5 秒），使用真实本地 DO／SQLite 运行时和模拟供应商，覆盖四协议、现代及旧版 MCP 客户端、幂等、续聊、取消、隔离、运行中持久输出和原生 length 结束。
- 默认沙箱中的两项测量测试因不允许监听本机回环端口而失败；允许监听后完整单测通过。没有把环境权限失败算作业务修复。

## 成本与未完成项

每次有语义变化的既有持久 checkpoint，新增一次紧凑进展行读取／更新；无语义变化时不写。阶段切换和工具业务状态变化另有低频记录。分页只读有界内容块与末块，不物化整条回答，也不强制缓冲器提交。正式平台 CPU、存储放大与操作计数尚未测量，不能据此宣称免费层余量已验证。

存储版本 4 仅由离线运维转换引入，启动仍拒绝旧版本；历史记录不补造观察时间。当前进展用于任务观测，备份的终态时间仍由既有 `generation.timing` 保存，恢复的旧任务不被恢复成正在生成。

实际上下文回执／提示词权限、可靠用量／费用、完整分支读取和导出、MCP 附件及版本、独立提案／审查、完整备份和生产迁移／上线仍是整个目标的后续工作。
