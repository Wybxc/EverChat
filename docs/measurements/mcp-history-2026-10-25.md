# MCP 分支读取与导出验证

2026-10-25；实现分支，尚未发布。

新增显式 Key→conversation 授权索引，以及对话发现、结构化分支读取和 Markdown 导出。新建时在同一事务授予权限；删除对话或 Key 时删除授权。存量授权只由本地迁移从单一 Key 的 MCP 来源建立，不访问时回填。

读取不加载完整消息正文。单页最多 8 个记录并限制序列化记录为 24 KiB；正文片段使用现有持久化内容分页，附件大选区以 JSON 片段读取，摘要覆盖 ID 分页。MCP 同时返回文本和 structuredContent，因此封装仍有约两倍开销。全局 revision 作为保守一致性边界：即使其他分支变动也重新读取，暂不维护额外服务端导出快照。

本地 SQLite 定向测试覆盖长消息、Unicode、附件大元数据、轮次范围、精准摘要归属、兄弟分支排除、删除 tombstone、活跃片段及快照变化。MCP／运维定向单测 23 项通过，类型检查通过。

真实本地 DO 集成 6 项通过（59.7 秒），覆盖四供应商协议、现代／legacy 客户端、幂等与取消、运行中分页、跨 Key 隔离、授权发现／完整分支读出／Markdown 导出、并发修改拒绝，以及桌面浅色／移动深色 Key 管理回归。全部使用模拟供应商，无真实模型费用。这不等于 Cloudflare Free CPU／存储放大验收。

尚未实施 MCP 附件上传、文件版本绑定和独立提案／审查；完整目标与离线迁移发布仍待后续完成。
