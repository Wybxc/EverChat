# 文本附件按需读取执行记录

日期：2026-10-31，生产离线校验完成于北京时间 11 月 1 日。功能代码、本地验收和生产离线升级校验完成，发布结果见本文末尾关联的 PR。本地合成数据不包含用户提供日志的正文，测试供应商均为本地模拟。

## 实现

- 统一网页选择、拖放、MCP 的文本分类；HTML／SVG／XML、未知与无后缀文本走严格 UTF-8 验证，保存原始 MIME，预览不执行内容。CSV 语法不完整仍可作为原文使用。
- 模型侧三个只读工具：`attachment_info`、`attachment_read`、`attachment_search`。固定文件版本与许可选区；UTF-8 字节坐标、跨块字面匹配、多关键词、重叠计数、位置、片段和续读游标。
- 自动／全文／按需输入统一进入预算、生成、摘要、分支与 MCP；关闭网页搜索仍可读取附件。初始清单明确 `contentRead: false`，后续步骤回执保留实际工具片段。
- R2 范围读取、64 KiB 稀疏索引、256 KiB 扫描批次；Workflow 每步最多推进 16 次 DO 批次，内部扫描不增加模型轮次。取消和根任务终态清理临时游标。
- 大于 1 MiB 普通文本增量准备并复用已验证的不可覆盖原始对象，避免重复写入全文。范围预览约 8 KiB；显式全文读取保留 32 MiB 工作集保护。
- 原始直传对象没有 R2 checksum 元数据时不误判不可用；准备时完整内容校验仍保留。范围读取不重新扫描全文，返回片段保留独立哈希。
- 复制／恢复保留规范文本、BOM、原始 MIME 与估算版本，流式建立索引；普通文本 ZIP 条目不再错误套用 PDF 的 32 MiB 边界。
- 存储版本 5 → 6；已有文本只通过本地维护工具备份、生成索引、写回及校验。普通业务请求不自动转换旧格式或重建历史索引。

## 本地验证

- 全部 581 项单元测试通过，覆盖 UTF-8、BOM／多字节边界、稀疏坐标、跨块及重叠匹配、权限选区、重启／重试、丢失写入清理、预算与输入回执、离线索引生成，以及 33 MiB 文本 ZIP 往返。
- 原生 workerd 运维集成通过（包含直传文本缺少 R2 checksum 元数据的情况），包含新增的索引 PUT／GET／DELETE、幂等、冲突和哈希保护。
- 首轮附件／备份／MCP 广泛回归 102 项中 95 项通过；7 项暴露旧测试假设及问题，逐项修正并定向复测。未将失败的首轮记为全通过。
- 定向回归包含四协议 `manifest → search → read → final`、MCP 多步骤输入回执、HTML 惰性预览和模式持久化；33 MiB 实际本地 R2 直传、增量准备及范围预览通过。
- 最终 17 项相关复测有 16 项通过；复制超时场景一次未进入测试暂停点，隔离复测及与实例重置场景的连续两项复测均通过；未复现业务逻辑错误。未以重试覆盖原始失败记录。
- 类型检查、生产构建及格式检查通过。
- WebKit 的 HTML 纯文本分页预览、模式刷新恢复和工具过程通过；Chromium 使用相同场景。本轮不宣称所有 WebKit 或已安装 PWA 真机回归完成。

## 工作集与本机基准

Node v26.5.0／macOS，单个 256 KiB ASCII 块循环扫描 128 次（合计 32 MiB），不物化整文件；密集模式搜索 `aaa`，统计重叠命中。此为本机算法基准，未包含 R2 网络、DO SQL、Workflow 计费或 Cloudflare CPU。

| 负载         | 关键词数 |       总 CPU |      总墙钟 | 结果                    |
| ------------ | -------: | -----------: | ----------: | ----------------------- |
| 无命中       |        1 |   103.178 ms |    99.48 ms | 0                       |
| 密集命中计数 |        1 |   157.540 ms |   154.39 ms | 33,554,430              |
| 无命中       |       16 |   795.214 ms |   797.53 ms | 0                       |
| 密集命中计数 |       16 | 1,470.768 ms | 1,472.80 ms | 536,870,880             |
| 增量索引     |        — |   198.347 ms |   192.66 ms | 512 个位置，24,814 字节 |

范围读取测试断言预览实际读取不超过 8,196 字节；工具扫描每个批次不超过 256 KiB，并通过每批重建执行器验证持久检查点。大文件的索引规模随文件长度线性增长，完整搜索也有线性成本；有界工作集不等于免费或无限时长。

## 平台证据边界

未创建额外 Cloudflare 测试资源，未调用付费模型。真实 CPU、峰值内存、冷／热缓存、R2 与 DO 账户用量对照仍未测得，继续跟随[独立资源排查](../plans/sync-worker-resource-investigation-plan.md)。扫描执行在 DO，普通 Worker 和 Workflow 不承担整文件 CPU 循环；不能把 DO 与 Workers Free 的 CPU 入口混用，也不能用上述 Node 数值证明免费层通过。
