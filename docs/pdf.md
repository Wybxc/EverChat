# PDF 文本输入

阶段 4 第 4 项。聊天框「添加文件」可选择包含文字的 PDF；提取结果带页码，使用现有私有文本预览、文件问答、草稿、离线队列和上下文预算。可以只发送 PDF，不要求视觉模型；PDF 中的图片不进入模型。

## 客户端提取与边界

使用 Mozilla [PDF.js](https://mozilla.github.io/pdf.js/getting_started/) 的 `pdfjs-dist`，在独立浏览器 Worker 中读取本地文件；按页流式读取已有文字，不渲染页面、表单、注释或脚本。中文 CMap 和标准字体资源随应用构建，通过明确名称的资源映射加载；不上传 PDF 到第三方解析服务、不从公共 CDN 加载解析器或字体。PDF 解析模块仅在选择 PDF 时加载。

原文件最多 5 MiB、50 页，全部提取结果包含页码标记后最多 64,000 个 UTF-16 码元／128 KiB。超过任一限制明确拒绝，不静默截断。30 秒期限覆盖模块冷加载、解析器加载及提取；超时或取消释放调用者并终止已创建的 Worker。切换对话、退出登录或取消上传也会终止当前提取。没有可提取文字、需要口令、损坏或不支持的 PDF 保留聊天草稿，不登记文件、不创建模型任务。

只提取 PDF 中已有文字，不处理扫描图像。字体编码、多栏、表格和排版可能影响文字与阅读顺序，不承诺视觉还原；复杂文件可以先重新导出或拆分。原文件仍可私有下载。

## 保存和任务

提取成功后，先保存原 PDF，再上传文本和页数／解析器版本。服务端检查已完成原文件、所属对话、原始 SHA-256、提取文本编码、大小、长度及元数据范围；标准 UTF-8 文本保存到私有 R2，DO 只保存解析状态、哈希、长度、版本、页数和引用。相同结果幂等复用，已绑定文件 ID 的不同文本或页数拒绝覆盖。

服务端不再运行 PDF 解析器，也不独立证明客户端声明的页数、阅读顺序或提取内容与 PDF 的语义一致。这些是同一登录用户提交的资料。哈希绑定用于固定原文件与提取结果，不能当作解析器执行的证明。

原文件及提取文本可靠保存并通过接受前校验后，才接受聊天任务。之后由 DO 读取固定文本引用，正文以普通文件资料发给四类协议；不依赖客户端继续在线，不把 PDF 二进制、公开 URL 或大块文字写入消息事件和任务上下文。开始模型调用前再次校验解析文本及原文件头元数据。已保存 PDF 可跨设备预览、刷新恢复草稿、离线排队及重新生成。

数量、近似 Tokens、历史／摘要、修改和引用删除规则复用[文本文件输入](documents.md)。每条消息最多 4 个文件，每次上下文最多 8 个／合计 128,000 字符；近似值不能用于计费。浏览器的页数和文本限制不能保证任意 PDF 的瞬时内存消耗；5 MiB 源文件、独立 Worker、时间上限和明确拒绝共同限定此原型入口。

## 故障、删除与后续

解析结果 R2 写入前持久化认领和租约，结果未知时由 Alarm 清理派生对象及 PDF 元数据，保留已完成的原文件。明确重新提交提取结果后可重试保存，不自动调用模型。已被消息或活动任务使用时阻止独立删除；删除最后来源后清理原文件、提取对象和 PDF 元数据。页面关闭前未保存完成的提取不视为已接受，可能需要重新选择文件。

含 PDF 的对话已支持[独立附件复制](attachment-copies.md)，原文件及提取文本独立保存。JSON 备份仍明确拒绝附件，包含文件的备份在阶段 4 第 5 项的下一检查点实现；文本导出保留文件名。Office 格式仍待验证托管解析服务。

参考 [PDF.js API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html) 的本地数据输入、Worker、`stopAtErrors` 和资源加载参数，以及 [streamTextContent](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib-PDFPageProxy.html) 的按块读取接口。包的当前实现和类型是本原型固定版本的运行依据；这些 API 不证明解析结果质量或 Cloudflare 费用。

固定 `pdfjs-dist` 为 6.4.299，锁文件安装通过。`pnpm check` 通过：197 项单元、172 项端到端、2 项 PWA，以及应用／Worker／工具类型检查和构建；测试文件的独立严格 TypeScript 检查通过。

11 项 PDF 浏览器场景使用真实 PDF.js Worker、隔离本地 DO／R2 和实际供应商 SDK，覆盖四类协议、只发送文件、页面关闭后完成、第二设备预览和原始字节、中文 CMap、大于普通文本上限的原文件、损坏／空白／加密／页数／文本上限拒绝、不可变哈希绑定、模块及 Worker 加载超时、路由取消，以及写入后实例重置的租约和元数据清理。另有生产构建测试验证实际 Worker 脚本与中文资源路径；供应商响应使用模拟数据，没有部署、创建远程桶或调用付费模型。
